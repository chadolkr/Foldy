Restricted capabilities packagedServices and localSystemServices: Foldy is a file manager whose main feature is instant file name search across every local drive. The package includes the same open-source search service that our MSI installer ships (foldy-index.exe, source: https://github.com/chadolkr/Foldy/tree/main/engine/foldy-index). It runs as LocalSystem because reading the NTFS Master File Table and the USN change journal requires a volume handle, which standard users cannot open. Without it, the app must walk every folder with the user's rights, which takes minutes on large drives and misses changes made while the app is closed.
What the service does: it reads only file names, sizes and times from NTFS metadata (never file contents) and keeps the list in %ProgramData%\Foldy. It answers only the Foldy app on the same PC through a local named pipe whose access list denies network logons and allows SYSTEM, Administrators and interactive users. Results never include other users' profile folders or recycle bins. In the Store package the service is started with --store and never downloads or installs anything; the Store updates the package.
How to test: install, open Foldy, wait for "Search: ready" in the status bar (a few seconds to a minute), then press Ctrl+Space and type part of any file name on C:.
