# 점검: 수다쟁이 Foldy (2026-11-20, 0.9.7 기준)

기준: 디자인 원칙 1.4 "수다쟁이 Foldy" — 기다리는 동안 아무것도 안 보이는 순간이 없나?

| 곳 | 전 | 후 |
| --- | --- | --- |
| [재시작하고 업데이트] 뒤 | Foldy가 닫히고 30초쯤 아무것도 안 보임 | 작은 진행 창: 기다리는 중 → 설치하는 중 → 다시 여는 중, 다른 Foldy 창 때문에 기다리면 알림, 실패·오래 걸림도 쉬운 말로 |
| 폴더 트리 펼치기 (느린 서버·네트워크) | 펼친 뒤 목록이 올 때까지 빈 채로 | 폴더 이름 옆에 "· 불러오는 중…" |
| SFTP 연결 단추 | "연결 중…" | "서버에 연결하는 중…" |

## 줄인 확인 창 (단추는 꼭 필요할 때만)

| 곳 | 전 | 후 |
| --- | --- | --- |
| 업데이트 확인 → 최신 | "최신 버전입니다" 창 + [확인] | 상태 줄에 "최신 버전이에요 … 새 버전이 나오면 알려 드릴게요" (실패는 이유가 중요해 창 유지) |
| 폴더 분석 → [휴지통으로] | "휴지통으로 옮길까요?" 확인 창 | 묻지 않고 옮긴 뒤 상태 줄에 "옮겼어요, 휴지통에서 되살릴 수 있어요" |

남겨 둔 확인 창 (되살릴 수 없거나 위험): 영구 삭제·빨리 지우기·SFTP 삭제, 휴지통 비우기, 새 서버 호스트 키, 문서 링크로 실행 파일·네트워크 위치 열기, 저장 못 한 메모 닫기, 태그를 저장소에 공유, 진단 기록 보내기, Git의 되돌릴 수 없는 작업, 업데이트를 지금 설치할지.

이미 말하고 있던 곳 (그대로 둠): 파일 목록 불러오기·검색(목록 오른쪽 아래 "불러오는 중"·"찾는 중 · Esc 취소"), 복사·이동·삭제(작업 창 진행률과 농구 아이들), 업데이트 확인(상태 줄 "업데이트 확인 중…"과 결과 창), 색인 연결 실패(상태 줄 "검색: 폴더 훑기 (색인 서비스 없음)"와 빠른 검색의 ⚠ 안내), 폴더 분석(분석 탭 진행 표시), 정리 도구(대화 창 "찾는 중"), 빠른 검색(블러드하운드와 걸린 시간).
