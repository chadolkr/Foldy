# UX 점검 1차 (2026-11-19, 0.3.17 기준)

장면 캡처(`build/doc-screenshots.ps1`, 예시 폴더)로 점검. 고대비·150% 이상 고해상도는 캡처로 확인하지 못함.

## 고친 것 (0.3.19)
1. 1366×768에서 사이드바 도구가 잘려 스크롤 → 넘치면 "최근 폴더"를 자동으로 접음.
2. 좁은 창에서 경로가 아이콘만 남음 → 검색 칸을 줄이고, Git 바가 보이면 겹치는 Git 칩을 숨김.
3. 처음 쓰는 사람 안내가 없음 → 30초 둘러보기(명령 목록 "둘러보기"로 다시).
4. 끝난 작업이 작업 창에 계속 남음 → 마무리 뒤 6초에 사라지고 실패만 남음.
5. 대화 창을 키보드로 닫을 수 없음 → Esc로 닫기(아무것도 바꾸지 않음).
6. 도움말의 옛 이름 "정리 도구" → "정리하기".
7. 금고 꺼내기 zip slip → 폴더 밖 이름을 막음(리뷰 PR #6과 합침).

## 괜찮았던 것
- 다크 테마 대비, 파일 이름 잘림 없음, 대화 창의 Enter = 첫 버튼.

## 사용자에게 물은 것
- A. 좁은 화면에서 각 창의 폴더 트리를 자동으로 숨길지 (추천: 숨김, Ctrl+B로 다시).
- B. 정리하기 메뉴가 10개를 넘으면 구분선 vs 하위 메뉴 (추천: 구분선).
