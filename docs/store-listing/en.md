## Product name

Foldy File Manager

## Description

A fast, smart file manager. Even offline.
Even better when you connect your AI.

Foldy is a free, open-source file manager that makes finding files, freeing up space and tidying up easy.
It looks and works like File Explorer, with the same right-click menus, drag and drop and shortcuts, so you can start right away without a manual.
Everything is explained in plain words, so first-time users and grandparents can use it too.

🏠 Website: https://chadolkr.github.io/Foldy/en/
See screenshots, a full guide and what changed in each version.


💛 Easy for everyone: it starts with what makes things hard
• Help appears where you're looking: as we get older, we take in less of the screen at a glance. So when something can't be done, Foldy tells you why where you're already looking: right under the mouse pointer, or next to where you're typing or what you selected.
• Plain words, not jargon: "file list" instead of "index", "file type" instead of "file extension".
• Asks only when it matters: anything that can be undone just happens. Foldy asks again only before things that can't be brought back.
• Ready without learning: big buttons, the same moves as File Explorer, and on/off always in the same place.

🔍 Find anything (Ctrl+Space)
• While Foldy is running, press Ctrl+Space in any window and a big search box appears.
• Files, apps, Windows settings, Control Panel and math, all in one box.
• Type the way you talk, like "clean up my downloads", and Foldy finds the right tool.
• See how many results there are, and more keep loading as you scroll.

💾 Free up space
• See what fills your disk at a glance, as big boxes and a ranked list.
• Foldy only suggests things that are safe to delete, like temp files, caches and developer folders that can be rebuilt.
• Progress is shown while it looks, and you can press "Stop searching" at any time.
• Deleting always goes to the Recycle Bin, so you can change your mind.

🧹 Tidy your Desktop, Downloads and folders
• Foldy first tells you what it found and what each button will do.
• Nothing is thrown away on its own. One click on Undo puts everything back.
• Even folders with hundreds of thousands of files get a plan quickly, and you can continue later if you stop.
• See where identical files are and pick the one to keep.
• Right before tidying, Foldy checks again that nothing has changed.

📁 Create folders from a template
• Pick one of 19 well-known methods and all the folders are made in one go.
• PARA, GTD, Johnny.Decimal, project management (PMBOK), records management (ISO 15489), research data, photo archive, home paperwork and more.
• Every template comes with a short guide on how to use it.

🗂️ Everyday work, made easier
• Two panes side by side: copy with drag and drop or one press of F5.
• Color tabs, and the folders you had open are still there next time.
• Look without opening: F3 previews photos, documents, PDFs and code. Notes (.md) are shown nicely formatted.
• Slow network drives and USB sticks don't freeze it. The list shows up first.
• Mistakes are OK: files overwritten while copying are kept aside for 7 days.
• Password-locked notes, and vaults that lock several files together.
• Kids play basketball while your files copy. You can turn it off in Settings.

👩‍💻 For developers
• See Git status the moment you open a folder.
• Open SFTP and SSH servers in a tab and use them like folders on your PC.

🤖 Even better when you connect your AI
Connect Foldy to an AI app like Claude, ask "find last year's quote", and the AI uses Foldy to find files on your PC.
It is off by default, read-only when on, and only works inside this computer.

🔒 Use it with peace of mind
• Every feature works offline. No ads, no analytics, no tracking.
• Crash reports are off by default, and Foldy asks before sending each one.
• Choose a larger text size. Dark and light mode follow Windows.
• Available in 한국어, English, Español, 日本語 and 简体中文.
• GPL-3.0 open source: anyone can read the code.

ℹ️ Good to know about the Store edition
• Microsoft Store keeps Foldy up to date.
• The Store edition includes the same fast search helper as the installer edition. It reads C: in seconds and builds file lists for USB and network drives on its own, so Windows may ask for administrator approval once during install.
• After you run Foldy once, Ctrl+Space opens the search box even when Foldy is closed. You can turn this off in Task Manager → Startup apps.
• The installer for work and offline PCs is on the website.

## What's new in this version

1.17.0
• In Find anything (Ctrl+Space), clicking a file or folder once opens its containing folder with it selected (same as Ctrl+Enter), and double-clicking opens the file (same as Enter). Apps, settings and Control Panel items still run with a single click.

1.16.0
• Downloads cleanup now shows the actual files first instead of just "10 files not opened in 90 days". Each file shows its size and the day it was last opened, with Open and Show in folder, so you can uncheck the ones you want to keep.

1.15.0
• The Store edition now includes the same fast search helper as the installer edition. It reads C: in seconds and finds files that changed while Foldy was closed.
• In the Store edition, Ctrl+Space now opens the search box even when Foldy is closed (a small helper starts when you sign in).

1.14.4
• In Find anything (Ctrl+Space), Ctrl+Enter opens the containing folder with the found file selected and shown near the middle of the list. Before, you sometimes had to scroll to see it.

1.14.2
• You can now drag the Find anything (Ctrl+Space) window to move it. Grab the short bar at the top or any empty spot. It remembers where you put it and opens there next time (or in the middle if that spot is off screen).
• Opening the search window now brings the Foldy window up too, even if it was minimized or behind another program.
• Desktop, Downloads, Documents, Pictures and Videos are now always at the top of Recent folders on the left, each with its own icon. Folders moved by OneDrive open in the right place.
