Store 판(MSIX)은 색인 서비스와 자체 업데이트가 없다 (docs/store.md). 그래서 검색 속도 숫자(0.003초 등)는 쓰지 않는다.

## 제품 이름

Foldy File Manager

## 설명

빠르고 똑똑한 파일 관리자, 오프라인에서도.
AI와 연결하면 더 편하게.

Foldy는 파일 찾기, 공간 늘리기, 정리를 쉽게 하도록 만든 무료 오픈소스 파일 관리자예요.
Windows 탐색기와 화면, 오른쪽 클릭 메뉴, 끌어 놓기, 단축키가 같아서 설명서 없이 바로 쓸 수 있어요.
처음 쓰는 분도, 할머니 할아버지도 쓸 수 있게 쉬운 말로 안내해요.

🏠 소개 페이지: https://chadolkr.github.io/Foldy/
화면 그림, 자세한 사용법, 버전마다 바뀐 점을 볼 수 있어요.


🔍 무엇이든 찾기 (Ctrl+Space)
• Foldy를 켜 두면 어느 창에서든 Ctrl+Space 한 번으로 큰 검색 칸이 떠요.
• 파일, 앱, Windows 설정, 제어판, 계산까지 한 칸에서 찾아요.
• "다운로드 정리해줘"처럼 말하듯 쳐도 알맞은 기능을 찾아 줘요.
• 찾은 개수가 보이고, 아래로 내리면 결과가 계속 나와요.

💾 공간 늘리기
• 무엇이 디스크를 차지하는지 큼직한 상자 그림과 순위로 한눈에 보여 줘요.
• 임시 파일, 캐시, 다시 만들 수 있는 개발 폴더처럼 지워도 괜찮은 것만 골라 줘요.
• 찾는 동안 진행이 보이고, 언제든 [그만 찾기]로 멈출 수 있어요.
• 지울 때는 휴지통으로만 옮겨서 마음이 바뀌면 되살릴 수 있어요.

🧹 바탕화면 · 다운로드 · 폴더 정리
• 무엇을 찾았는지, 누르면 어떻게 되는지 먼저 말해 드려요.
• 저절로 버리지 않아요. [되돌리기] 한 번이면 원래대로예요.
• 파일이 수십만 개인 큰 폴더도 정리 계획을 빨리 만들고, 중간에 끊겨도 이어서 해요.
• 똑같은 파일이 어디어디 있는지 보여 주고, 남길 것을 직접 골라요.
• 정리하기 바로 전에 파일이 바뀌지 않았는지 한 번 더 확인해요.

📁 템플릿으로 폴더 만들기
• 잘 알려진 정리법 19가지를 고르면 폴더가 한 번에 생겨요.
• PARA, GTD, Johnny.Decimal, 프로젝트 관리 표준(PMBOK), 기록 관리 표준(ISO 15489), 연구 데이터, 사진 보관, 생활·가정 서류 등.
• 템플릿마다 어떻게 쓰는지 안내가 함께 있어요.

🗂️ 매일 쓰는 일도 더 편하게
• 두 창이 나란히: 끌어 놓기나 F5 한 번으로 복사해요.
• 색깔 탭, 그리고 열어 둔 폴더는 다음에 켜도 그대로예요.
• 열지 않고 보기: F3으로 사진, 문서, PDF, 코드를 바로 미리 봐요. 메모(.md)는 읽기 좋게 보여 줘요.
• 느린 네트워크 드라이브나 USB도 멈추지 않고 목록부터 보여 줘요.
• 실수해도 괜찮아요: 복사하다 덮어쓴 파일은 7일 동안 따로 보관해요.
• 비밀번호를 거는 잠긴 메모, 파일 여러 개를 함께 잠그는 금고.
• 복사하는 동안 아이들이 농구를 해요. 설정에서 끌 수 있어요.

👩‍💻 개발자라면 더
• 폴더에 들어가는 순간 Git 상태가 보여요.
• SFTP·SSH 서버도 탭으로 열어 내 PC 폴더처럼 다뤄요.

🤖 AI와 연결하면 더 편하게
Claude 같은 AI 앱에 Foldy를 연결하면 "작년 견적서 찾아 줘"처럼 물어볼 때 AI가 Foldy로 내 PC의 파일을 찾아요.
연결은 기본으로 꺼져 있고, 켜도 읽기 전용이며 이 컴퓨터 안에서만 동작해요.

🔒 안심하고 쓰세요
• 인터넷 없이 모든 기능이 돼요. 광고, 사용 통계, 추적이 없어요.
• 오류 보고는 기본으로 꺼져 있고, 보낼 때마다 먼저 물어봐요.
• 글자 크기를 크게 고를 수 있고, 다크·라이트 모드는 Windows 설정을 따라요.
• 한국어, English, Español, 日本語, 简体中文을 지원해요.
• 누구나 코드를 볼 수 있는 GPL-3.0 오픈소스예요.

ℹ️ Store 판에서 알아 두세요
• 업데이트는 Microsoft Store가 알아서 해요.
• Store 판에는 드라이브 전체를 미리 읽어 두는 서비스가 없어서, 아주 큰 드라이브에서는 찾기가 조금 느릴 수 있어요.
• Ctrl+Space는 Foldy가 켜져 있을 때 동작해요.
• 회사·오프라인 PC용 설치 파일과 미리 읽어 두는 빠른 찾기는 소개 페이지에서 받을 수 있어요.

## 이 버전의 새로운 기능

1.3.0 뒤에 나온 개선을 모았어요.
• 큰 폴더 정리: 파일이 수십만 개여도 계획을 빨리 만들고, 끊겨도 이어서 해요. 같은 파일이 어디 있는지 보고 남길 것을 골라요.
• 무엇이든 찾기: 찾은 수가 보이고, 아래로 내리면 이어서 나와요.
• 지워도 되는 폴더 찾기: 진행이 보이고, 중간에 멈출 수 있고, 더 많은 종류를 찾아요.
• 폴더 템플릿 6가지를 더했어요.
• 선택한 이름을 천천히 한 번 더 눌러 바꿀 수 있어요.
• 화면 글을 더 쉬운 말로 바꿨어요.

## 제품 기능 (한 줄에 하나)

- Ctrl+Space로 파일·앱·Windows 설정·계산을 한 칸에서 찾기
- 말하듯 쳐도 알맞은 기능을 찾아 주는 검색, 찾은 개수 표시
- 디스크를 차지하는 폴더를 상자 그림과 순위로 보기
- 지워도 되는 임시 파일·캐시·개발 폴더만 골라 휴지통으로
- 찾는 동안 진행 표시, 언제든 [그만 찾기]
- 바탕화면·다운로드를 물어보며 정리, [되돌리기] 한 번
- 수십만 개 파일의 큰 폴더도 빠르게 정리하고 이어서 하기
- 같은 파일 위치를 보고 남길 것 고르기
- PARA·GTD·PMBOK 등 잘 알려진 폴더 템플릿 19가지
- 탐색기와 같은 단축키·오른쪽 클릭·끌어 놓기
- 두 창, 색깔 탭, 열어 둔 폴더 기억
- F3으로 사진·문서·PDF·코드 미리 보기
- 느린 네트워크 드라이브·USB도 멈추지 않고 목록부터
- 복사하다 덮어쓴 파일 7일 보관
- 비밀번호 메모와 여러 파일을 잠그는 금고
- Git 상태 보기, SFTP·SSH 서버 탭
- AI 앱 연결(읽기 전용, 이 컴퓨터 안에서만)
- 오프라인에서 모든 기능, 광고·추적 없음
- 큰 글자, 다크·라이트 모드, 5개 언어
- 무료 오픈소스(GPL-3.0), 소개 페이지 chadolkr.github.io/Foldy

## 짧은 설명
