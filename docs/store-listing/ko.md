# Microsoft Store 등록 정보: 한국어 (ko-KR)

Partner Center → Foldy File Manager → 스토어 등록 정보 → 한국어 칸에 그대로 붙여 넣는다.
Store 판(MSIX)은 색인 서비스와 자체 업데이트가 없다 (docs/store.md). 그래서 검색 속도 숫자(0.003초 등)는 쓰지 않는다.

## 제품 이름

Foldy File Manager

## 설명

빠르고 똑똑한 파일 관리자, 오프라인에서도. AI와 연결하면 더 편하게.

Foldy는 Windows 탐색기처럼 익숙한 화면에서 파일 찾기, 공간 늘리기, 바탕화면 정리를 쉽게 하도록 만든 무료 오픈소스 파일 관리자예요. 오른쪽 클릭 메뉴, 끌어 놓기, 단축키가 탐색기와 같아서 설명서 없이 바로 쓸 수 있어요.

■ 가장 많이 쓰는 네 가지
• 무엇이든 찾기: 어디서든 Ctrl+Space를 누르면 큰 검색 칸이 떠요. 파일, 앱, Windows 설정, 계산까지 한 칸에서 해요. "다운로드 정리해줘"처럼 말하듯 쳐도 알맞은 기능을 찾아 줘요.
• 공간 늘리기: 무엇이 디스크를 차지하는지 큼직한 상자 그림으로 보여 줘요. 임시 파일, 캐시처럼 지워도 괜찮은 것만 골라 주고, 지울 때는 휴지통으로만 옮겨요.
• 바탕화면, 다운로드, 폴더 정리: 무엇을 찾았는지, 누르면 어떻게 되는지 먼저 말해 드려요. 저절로 버리지 않고, [되돌리기] 한 번이면 원래대로예요.
• 템플릿으로 폴더 만들기: PARA, 프로젝트 관리 표준(PMBOK), 연구·학습, 사진 보관 같은 정리법을 고르면 폴더가 한 번에 생겨요.

■ 매일 쓰는 일도 더 편하게
• 두 창이 나란히: 끌어 놓기나 F5 한 번으로 복사. 탭은 색깔별로, 열어 둔 폴더는 다음에도 그대로예요.
• 열지 않고 보기: F3으로 사진, 문서, PDF, 코드를 바로 미리 봐요. 메모(.md)는 읽기 좋게 보여 줘요.
• 느린 드라이브도 멈추지 않아요: 네트워크 드라이브나 USB가 느려도 목록부터 보여 줘요.
• 실수해도 되살려요: 복사하다 덮어쓴 파일은 7일 동안 따로 보관해요.
• 잠긴 메모와 금고: 비밀번호를 거는 메모, 파일 여러 개를 함께 잠그는 금고.
• 복사가 재밌어요: 복사하는 동안 아이들이 농구를 해요. 설정에서 끌 수 있어요.
• 개발자라면 더: 폴더에 들어가는 순간 Git 상태가 보이고, SFTP·SSH 서버도 탭으로 열어요.

■ AI와 연결하면 더 편하게
Claude 같은 AI 앱에 Foldy를 연결하면, "작년 견적서 찾아 줘"처럼 물어볼 때 AI가 Foldy로 내 PC의 파일을 찾아요. 연결은 기본으로 꺼져 있고, 켜도 읽기 전용이며 이 컴퓨터 안에서만 동작해요.

■ 안심하고 쓰세요
• 인터넷 없이 모든 기능이 돼요. 광고, 사용 통계, 추적이 없어요.
• 오류 보고는 기본으로 꺼져 있고, 보낼 때마다 먼저 물어봐요.
• 글자 크기를 크게 고를 수 있고, 다크·라이트 모드를 Windows 설정에 맞춰요.

## 이 버전의 새로운 기능

Microsoft Store에 처음 나왔어요. 무엇이든 찾기(Ctrl+Space), 공간 늘리기, 바탕화면·다운로드 정리, 템플릿으로 폴더 만들기, AI 연결을 모두 담았고 5개 언어를 지원해요.

## 제품 기능 (한 줄에 하나)

- Ctrl+Space로 파일·앱·Windows 설정·계산을 한 칸에서 찾기
- 말하듯 쳐도 알맞은 기능을 찾아 주는 검색
- 디스크를 차지하는 폴더를 상자 그림과 순위로 보기
- 지워도 되는 임시 파일·캐시만 골라 휴지통으로
- 바탕화면·다운로드를 물어보며 정리, 되돌리기 한 번
- PARA·프로젝트 관리 표준 등 폴더 템플릿
- 탐색기와 같은 단축키·오른쪽 클릭·끌어 놓기
- 두 창, 색깔 탭, 열어 둔 폴더 기억
- F3으로 사진·문서·PDF·코드 미리 보기
- 덮어쓴 파일 7일 보관
- 비밀번호 메모와 여러 파일을 잠그는 금고
- Git 상태 보기, SFTP·SSH 서버 탭
- AI 앱 연결(읽기 전용, 이 컴퓨터 안에서만)
- 오프라인에서 모든 기능, 광고·추적 없음
- 큰 글자, 다크·라이트 모드, 5개 언어

## 짧은 설명

빠르고 똑똑한 파일 관리자, 오프라인에서도. Ctrl+Space로 무엇이든 찾고, 공간을 늘리고, 바탕화면과 다운로드를 물어보며 정리해요. 탐색기처럼 익숙해서 설명서가 필요 없어요. AI와 연결하면 더 편하게.
