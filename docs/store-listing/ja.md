## 製品名

Foldy File Manager

## 説明

速くて賢いファイル マネージャー。オフラインでも。
AI とつなぐと、もっと便利に。

Foldy は、ファイル探し、空き容量づくり、整理をかんたんにする無料のオープンソース ファイル マネージャーです。
画面も右クリック メニューもドラッグ アンド ドロップもショートカットもエクスプローラーと同じなので、説明書なしですぐに使えます。
やさしい言葉で案内するので、はじめての方やおじいちゃん・おばあちゃんでも使えます。

🏠 紹介ページ: https://chadolkr.github.io/Foldy/ja/
画面の様子、くわしい使い方、バージョンごとの変更点を見られます。


💛 だれでもかんたんに：不便さから始めました
• 案内は視線の先に：年齢とともに、一度に見える範囲は狭くなります。だから、できないときの理由はいま見ているところに表示します。マウスならポインターのすぐ下、キーボードなら入力している場所や選んだもののすぐ横です。
• 難しい言葉より、やさしい言葉：「インデックス」ではなく「ファイル一覧」、「拡張子」ではなく「ファイルの種類」。
• 確認は本当に必要なときだけ：元に戻せることはすぐに実行し、取り消せないことだけもう一度確認します。
• 覚えなくてもすぐ使える：大きなボタン、エクスプローラーと同じ操作、オン・オフはいつも同じ場所。

🔍 なんでも検索 (Ctrl+Space)
• Foldy を起動しておけば、どのウィンドウからでも Ctrl+Space で大きな検索欄が開きます。
• ファイル、アプリ、Windows の設定、コントロール パネル、計算まで 1 つの欄で。
• 「ダウンロードを整理して」のように話すように入力しても、ぴったりの機能を見つけます。
• 見つかった件数が表示され、下へスクロールすると続きが出ます。

💾 空き容量をふやす
• 何がディスクを使っているか、大きな四角の図とランキングでひと目でわかります。
• 一時ファイル、キャッシュ、作り直せる開発用フォルダーなど、消しても大丈夫なものだけを選びます。
• 探している間は進み具合が見え、いつでも「探すのをやめる」で止められます。
• 消すときはごみ箱へ移すだけなので、あとから戻せます。

🧹 デスクトップ・ダウンロード・フォルダーの整理
• 何が見つかったか、押すとどうなるかを先にお知らせします。
• 勝手に捨てません。[元に戻す] を 1 回押せば元どおりです。
• ファイルが何十万個ある大きなフォルダーでも計画をすばやく作り、途中で止めても続きから進められます。
• 同じファイルがどこにあるかを見て、残すものを自分で選べます。
• 整理する直前に、ファイルが変わっていないかもう一度確かめます。

📁 テンプレートでフォルダーを作る
• よく知られた整理法 19 種類から選ぶと、フォルダーが一度にできあがります。
• PARA、GTD、Johnny.Decimal、プロジェクト管理 (PMBOK)、記録管理 (ISO 15489)、研究データ、写真の保管、暮らしの書類など。
• どのテンプレートにも使い方の案内がついています。

🗂️ 毎日の作業ももっと楽に
• 2 つのウィンドウを並べて: ドラッグ アンド ドロップか F5 を 1 回押すだけでコピー。
• 色分けできるタブ。開いていたフォルダーは次に起動してもそのままです。
• 開かずに見る: F3 で写真、文書、PDF、コードをすぐプレビュー。メモ (.md) は読みやすく表示します。
• 遅いネットワーク ドライブや USB でも止まらず、一覧から先に表示します。
• 失敗しても大丈夫: コピー中に上書きしたファイルは 7 日間別に保管します。
• パスワード付きのメモと、複数のファイルをまとめてロックする金庫。
• コピーの間、子どもたちがバスケットボールをします。設定でオフにできます。

👩‍💻 開発者ならさらに
• フォルダーを開いた瞬間に Git の状態がわかります。
• SFTP・SSH サーバーもタブで開き、PC のフォルダーと同じように扱えます。

🤖 AI とつなぐと、もっと便利に
Claude などの AI アプリに Foldy をつなぐと、「去年の見積書を探して」と頼んだとき、AI が Foldy を使って PC のファイルを探します。
接続は最初はオフで、オンにしても読み取り専用、このコンピューターの中だけで動きます。

🔒 安心して使えます
• インターネットなしですべての機能が使えます。広告、利用統計、追跡はありません。
• エラー報告は最初はオフで、送るたびに先に確認します。
• 文字を大きくでき、ダーク・ライト モードは Windows の設定に合わせます。
• 한국어、English、Español、日本語、简体中文 に対応しています。
• だれでもコードを見られる GPL-3.0 のオープンソースです。

ℹ️ Store 版について
• 更新は Microsoft Store が自動で行います。
• Store 版にもインストーラー版と同じ高速検索ヘルパーが入っています。C: は数秒で読み込み、USB やネットワーク ドライブの一覧も自動で作ります。そのため、インストール時に Windows が一度だけ管理者の許可を求めることがあります。
• 一度 Foldy を起動すると、次からは Foldy を閉じていても Ctrl+Space で検索窓が開きます。タスク マネージャー → スタートアップ アプリでオフにできます。
• 会社やオフラインの PC 向けのインストーラーは紹介ページから入手できます。

## このバージョンの新機能

1.15.0
• Store 版にもインストーラー版と同じ高速検索ヘルパーが入りました。C: を数秒で読み込み、Foldy を閉じている間に変わったファイルもすぐ見つかります。
• Store 版でも、Foldy を閉じていても Ctrl+Space で検索窓が開きます (サインイン時に小さなヘルパーが起動します)。

1.14.4
• なんでも検索 (Ctrl+Space) で Ctrl+Enter を押して入っているフォルダーを開くと、見つけたファイルが選ばれた状態で一覧の真ん中あたりに見えます。以前はスクロールしないと見えないことがありました。

1.14.2
• なんでも検索 (Ctrl+Space) の画面をドラッグして動かせるようになりました。上の短いバーか空いている所をつかんでドラッグします。動かした場所を覚えていて、次もそこに開きます (その場所が画面の外なら中央に)。
• 検索画面を開くと Foldy の画面も一緒に前に出ます。最小化していても、ほかのアプリの後ろにあっても大丈夫です。
• 左のメニューの最近のフォルダーのいちばん上に、デスクトップ・ダウンロード・ドキュメント・ピクチャ・ビデオがいつも出ます。フォルダーごとに絵が違い、OneDrive に移ったフォルダーも本当の場所で開きます。

1.14.1
• 同じ画面の中でファイルやフォルダーを別のフォルダーの上にドラッグすると、そのフォルダーへ移動します。ドロップ先の行に枠が表示されます。
