## 製品名

Foldy File Manager

## 説明

速くて賢いファイルマネージャー、オフラインでも。AI とつなぐともっと便利に。

Foldy は、ファイル探し、空き容量の確保、デスクトップの整理を簡単にする無料のオープンソース ファイルマネージャーです。画面はエクスプローラーとそっくりで、右クリック メニュー、ドラッグ アンド ドロップ、ショートカットも同じなので、説明書なしですぐに使えます。

■ いちばんよく使う 4 つ
• 何でも検索: どこからでも Ctrl+Space を押すと大きな検索欄が開きます。ファイル、アプリ、Windows の設定、計算までひとつの欄で。「ダウンロードを整理して」のように話すように入力しても、合う機能を見つけます。
• 空き容量を増やす: 何がディスクを使っているかを大きな箱の図で見せます。一時ファイルやキャッシュなど消してよいものだけを提案し、削除はいつもごみ箱へ移すだけです。
• デスクトップ、ダウンロード、フォルダーの整理: 何が見つかったか、ボタンを押すとどうなるかを先にお知らせします。勝手に捨てることはなく、[元に戻す] を一度押せば元どおりです。
• テンプレートでフォルダー作成: PARA、プロジェクト管理 (PMBOK)、研究・学習、写真の保管などを選ぶと、フォルダーが一度にできます。

■ 毎日の作業ももっと楽に
• 2 画面を並べて: ドラッグするか F5 ひとつでコピー。タブは色分けでき、開いていたフォルダーは次回もそのままです。
• 開かずに見る: F3 で写真、文書、PDF、コードをすぐにプレビュー。メモ (.md) は読みやすく表示します。
• 遅いドライブでも固まらない: ネットワーク ドライブや USB が遅くても、まず一覧を表示します。
• 失敗しても大丈夫: コピーで上書きされたファイルは 7 日間別に保管します。
• パスワード付きメモと、複数のファイルをまとめて守る金庫。
• コピーが楽しい: コピー中は子どもたちがバスケットボールをします。設定でオフにできます。
• 開発者向け: フォルダーを開いた瞬間に Git の状態が見え、SFTP・SSH サーバーもタブで開けます。

■ AI とつなぐともっと便利に
Claude などの AI アプリに Foldy をつなぐと、「去年の見積書を探して」と聞いたときに AI が Foldy を使って PC のファイルを探します。初期状態はオフで、オンにしても読み取り専用、このコンピューターの中だけで動きます。

■ 安心して使えます
• すべての機能がインターネットなしで動きます。広告、利用統計、追跡はありません。
• エラー報告は初期状態でオフで、送る前に毎回確認します。
• 文字を大きくでき、ダーク・ライト モードは Windows に合わせます。
• 한국어、English、Español、日本語、简体中文 に対応しています。
• GPL-3.0 のオープンソース: https://github.com/chadolkr/Foldy

ご注意: Store 版には、ドライブ全体を前もってインデックス化するサービスが入っていません。検索はいま開いているフォルダーの中を直接探します。更新は Microsoft Store が行います。
