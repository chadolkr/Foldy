## 产品名称

Foldy File Manager

## 说明

快速又聪明的文件管理器，离线也能用。
连接 AI，更加方便。

Foldy 是一款免费的开源文件管理器，让查找文件、腾出空间和整理变得简单。
界面、右键菜单、拖放和快捷键都和文件资源管理器一样，不看说明书也能马上上手。
所有提示都用浅显的话来说明，第一次用的人和爷爷奶奶也能轻松使用。

🏠 介绍页面：https://chadolkr.github.io/Foldy/zh-cn/
可以看到界面截图、详细用法和每个版本的更新内容。


💛 人人都能轻松用：从让人不方便的地方出发
• 提示就在视线里：年纪越大，一眼能看到的范围越小。所以操作不了的时候，原因就显示在你正在看的地方：用鼠标时在指针正下方，用键盘时在输入的位置或选中的东西旁边。
• 说大白话，不说术语：用“文件列表”代替“索引”，用“文件类型”代替“扩展名”。
• 只在必要时才问：能撤销的事直接做，只有无法恢复的操作才会再确认一次。
• 不用学就会用：大按钮、和文件资源管理器一样的操作、开关总在同一个位置。

🔍 查找任何内容（Ctrl+Space）
• Foldy 运行时，在任何窗口按 Ctrl+Space 就会出现大搜索框。
• 文件、应用、Windows 设置、控制面板、计算，都在一个框里完成。
• 像说话一样输入，例如“整理我的下载”，Foldy 也能找到合适的功能。
• 显示结果数量，向下滚动会继续加载。

💾 腾出空间
• 用大方块图和排行一眼看清是什么占满了磁盘。
• 只挑出可以安全删除的内容，例如临时文件、缓存和可以重新生成的开发文件夹。
• 查找时能看到进度，随时可以点“停止查找”。
• 删除时只移到回收站，改变主意还能恢复。

🧹 整理桌面、下载和文件夹
• 先告诉你找到了什么、点下去会发生什么。
• 不会自动丢弃任何东西。点一次“撤销”就能恢复原样。
• 即使文件夹里有几十万个文件，也能很快制定整理计划，中途停下也能接着做。
• 查看相同文件分别在哪里，自己选择保留哪一个。
• 整理前会再次确认文件没有变化。

📁 用模板创建文件夹
• 从 19 种知名整理方法中选一种，文件夹一次就建好。
• PARA、GTD、Johnny.Decimal、项目管理（PMBOK）、档案管理（ISO 15489）、研究数据、照片归档、家庭生活文件等。
• 每个模板都附有使用说明。

🗂️ 日常工作更轻松
• 双窗格并排：拖放或按一次 F5 即可复制。
• 彩色标签页，打开过的文件夹下次启动时仍然保留。
• 不打开也能看：按 F3 直接预览照片、文档、PDF 和代码。笔记（.md）以易读的格式显示。
• 慢速网络驱动器和 U 盘也不会卡住，先显示文件列表。
• 出错也不怕：复制时被覆盖的文件会单独保留 7 天。
• 带密码的锁定笔记，以及能把多个文件一起锁起来的保险箱。
• 复制文件时，小朋友们会打篮球。可以在设置中关闭。

👩‍💻 开发者专属
• 一打开文件夹就能看到 Git 状态。
• 在标签页中打开 SFTP 和 SSH 服务器，像本地文件夹一样使用。

🤖 连接 AI，更加方便
把 Foldy 连接到 Claude 等 AI 应用后，问一句“找一下去年的报价单”，AI 就会通过 Foldy 在你的电脑上查找文件。
连接默认关闭，开启后也只读，并且只在这台电脑内运行。

🔒 放心使用
• 所有功能离线可用。没有广告、使用统计和跟踪。
• 错误报告默认关闭，每次发送前都会先询问。
• 可以选择更大的字号，深色和浅色模式跟随 Windows 设置。
• 支持 한국어、English、Español、日本語 和简体中文。
• GPL-3.0 开源，任何人都可以查看代码。

ℹ️ 关于 Store 版
• 由 Microsoft Store 自动更新。
• Store 版也包含与安装程序版相同的快速查找助手。几秒内读完 C:，并自动为 U 盘和网络驱动器建立列表，因此安装时 Windows 可能会请求一次管理员许可。
• 运行一次 Foldy 后，即使 Foldy 已关闭，按 Ctrl+Space 也能打开查找框。可在任务管理器 → 启动应用中关闭。
• 适用于公司电脑和离线电脑的安装程序可在介绍页面获取。

## 此版本的新增功能

1.16.0
• 整理下载文件夹时，不再只说“10 个文件超过 90 天没打开”，而是先列出是哪些文件。每个文件都显示大小和上次打开的日期，可以“打开看看”或“在文件夹中显示”，想保留的取消勾选即可。

1.15.0
• Store 版现在也包含与安装程序版相同的快速查找助手。几秒内读完 C:，Foldy 关闭期间改动的文件也能马上找到。
• Store 版中，即使 Foldy 已关闭，按 Ctrl+Space 也能打开查找框（登录时会启动一个小助手）。

1.14.4
• 在“查找任何内容”（Ctrl+Space）中按 Ctrl+Enter 打开所在文件夹时，找到的文件会被选中并显示在列表中间附近。以前有时需要滚动才能看到。

1.14.2
• 现在可以拖动"查找任何内容"（Ctrl+Space）窗口来移动它。抓住顶部的短横条或任意空白处拖动即可。它会记住你放的位置，下次在那里打开 (如果那个位置在屏幕外，就在中间打开)。
• 打开搜索窗口时，Foldy 主窗口也会一起显示，即使它已最小化或在其他程序后面。
• 左侧“最近的文件夹”最上方现在始终显示桌面、下载、文档、图片、视频，每个都有自己的图标。被 OneDrive 移动的文件夹也会在正确的位置打开。
