## 产品名称

Foldy File Manager

## 说明

快速智能的文件管理器，离线也能用。连接 AI 更方便。

Foldy 是一款免费开源的文件管理器，让找文件、腾空间、整理桌面都变得简单。界面和文件资源管理器几乎一样，右键菜单、拖放和快捷键也都相同，不用看说明书就能上手。

■ 最常用的四件事
• 什么都能找：在任何地方按 Ctrl+Space，就会弹出一个大搜索框。文件、应用、Windows 设置、计算，一个框全搞定。像说话一样输入“整理下载文件夹”，Foldy 也能找到合适的功能。
• 腾出空间：用大方块图告诉你是什么占满了磁盘。只建议可以放心删除的内容，比如临时文件和缓存，删除时也只是移到回收站。
• 整理桌面、下载和文件夹：先告诉你找到了什么、按下按钮会发生什么。不会自动丢弃任何东西，点一下 [撤销] 就恢复原样。
• 用模板创建文件夹：选择 PARA、项目管理 (PMBOK)、研究学习、照片归档等方法，文件夹一次建好。

■ 日常工作也更轻松
• 双窗格并排：拖放或按一下 F5 就能复制。标签页可以分颜色，打开的文件夹下次还在。
• 不打开也能看：按 F3 直接预览照片、文档、PDF 和代码。笔记 (.md) 会排版得清清楚楚。
• 慢速驱动器也不卡：网络驱动器或 U 盘再慢，也会先显示列表。
• 出错也能找回：复制时被覆盖的文件会另外保留 7 天。
• 加密笔记和保险箱：给笔记加密码，或把多个文件一起锁进保险箱。
• 复制也有趣：复制时孩子们在打篮球。可以在设置中关闭。
• 开发者专属：一进文件夹就能看到 Git 状态，SFTP 和 SSH 服务器也能在标签页中打开。

■ 连接 AI 更方便
把 Foldy 连接到 Claude 等 AI 应用，问一句“帮我找去年的报价单”，AI 就会通过 Foldy 在电脑里查找文件。此功能默认关闭，开启后也是只读的，并且只在这台电脑内运行。

■ 放心使用
• 所有功能无需联网。没有广告、没有使用统计、没有跟踪。
• 错误报告默认关闭，每次发送前都会先询问。
• 可以选择更大的字号，深色和浅色模式跟随 Windows。
• 支持 한국어、English、Español、日本語、简体中文。
• GPL-3.0 开源：https://github.com/chadolkr/Foldy

请注意：Store 版不包含预先为整个驱动器建立索引的服务。搜索会直接在当前打开的文件夹中查找。更新由 Microsoft Store 自动完成。

## 此版本的新增功能

自 1.3.0 以来的改进：
• 整理大文件夹：即使有几十万个文件也能很快制定计划，并可稍后继续。可查看相同文件的位置并选择保留哪一个。
• 查找任何内容：显示结果数量，向下滚动会继续加载。
• 查找可安全删除的文件夹：显示进度、可中途停止，并能找到更多类型。
• 新增 6 种文件夹模板。
• 再次慢速单击已选中的名称即可重命名。
• 界面文字更加通俗易懂。
