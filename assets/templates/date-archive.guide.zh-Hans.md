# 按日期归档 使用方法

> 不用纠结放哪里的方式。只要把文件放进它产生日期所在的 年-月 文件夹即可。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **年份（2026）** | 当年的 年-月 文件夹 | 不直接放文件 |
| **年-月（2026-11）** | 当月产生或收到的文件 | 长期反复修改的工作文件 |

比起按主题查找的资料，更适合过去后很少再看的记录（收据、缴费单、截图、收到的文件）。

## 示例树

```
归档/
└─ 2026/
   ├─ 2026-10/
   └─ 2026-11/
      ├─ 2026-11-03_会议记录.md
      └─ 2026-11-18_电费.pdf
```

## 命名规则

按 日期_内容 的顺序命名。按名称排序就是按时间排序。

| 对象 | 规则 | 例子 |
|---|---|---|
| 文件 | YYYY-MM-DD_内容 | `2026-11-18_电费.pdf` |
| 文件夹 | YYYY-MM | `2026-11` |

## 保持整洁的诀窍

- 换月时新建一个 年-月 文件夹。在同一个归档上再次使用此模板，只会创建缺少的文件夹。
- 日期统一用“产生的日期”。有的用收到日期、有的用写作日期就会混乱。
- 也可以用文件夹整理中的“按日期”方式，把已经堆积的文件移进这个结构。

## 这些情况适合其他风格

- 需要按项目或主题查找 → **PARA** 或 **Johnny.Decimal**
- 照片和视频 → **照片与视频归档**（日期_活动名 + 单独的 RAW）
