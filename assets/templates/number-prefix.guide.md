# 번호·날짜 붙이기 사용법

> 가장 쉬운 정리법이에요. 폴더 앞에 번호를 붙이면 순서가 늘 같고, 파일 이름을 날짜로 시작하면 이름순이 곧 날짜순이 돼요.

| 폴더 | 넣는 것 |
|---|---|
| **00_받은 파일** | 일단 여기에. 받은 파일, 어디 둘지 아직 모르는 것 (맨 위에 있어서 늘 눈에 띄어요) |
| **01_진행중** | 지금 하고 있는 일 |
| **02_자료** | 자주 보는 참고 자료 |
| **03_완료** | 끝났지만 가끔 보는 것 |
| **99_보관** | 오래돼서 거의 안 보는 것 (99라서 늘 맨 아래) |

## 받은 파일 칸 쓰는 법

1. 새 파일은 고민하지 말고 **00_받은 파일**에 넣어요.
2. 일주일에 한 번, 00_받은 파일을 비우면서 01~03으로 나눠요.
3. 다 비우면 끝! 쌓이지 않는 게 핵심이에요.

## 파일 이름

`2026-11-19_보고서.docx`처럼 **날짜_내용**으로 지으면 이름순으로만 봐도 날짜순으로 줄을 서요.

## 이럴 땐 다른 스타일을

- 진행 중인 일과 계속 맡는 일을 나눠 보고 싶다 → **PARA**
- 폴더가 아주 많아 번호로 바로 찾아가고 싶다 → **Johnny.Decimal**
- 사진·스캔처럼 날짜가 전부인 자료 → **날짜별 보관함**
