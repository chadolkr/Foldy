# 디자인·창작 자산 사용법

> 건드리면 안 되는 것(원본), 만드는 중인 것(작업), 결과물(내보내기), 영감(참고)을 섞지 않는 네 칸입니다.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 | 넣지 않는 것 |
|---|---|---|
| **원본** | 받은 이미지·사진·소재, 폰트 | 고친 파일 |
| **작업** | 작업 파일(psd, ai, fig, 프로젝트 파일)과 버전 | 완성본 |
| **내보내기** | 전달·게시용으로 뽑은 결과 (png, jpg, pdf, mp4) | 작업 중인 파일 |
| **참고** | 레퍼런스, 무드보드, 가이드라인 | 내가 만든 결과 |

## 예시 트리

```
브랜드로고/
├─ 원본/
├─ 작업/
│  ├─ 로고_메인_v2.ai
│  └─ 로고_메인_v3.ai
├─ 내보내기/
│  ├─ 로고_웹_512.png
│  └─ 로고_인쇄.pdf
└─ 참고/
```

## 이름 규칙

| 대상 | 규칙 | 예 |
|---|---|---|
| 작업 파일 | 작업명_내용_v버전 | `로고_메인_v3.ai` |
| 내보낸 파일 | 작업명_용도_크기 | `로고_웹_512.png` |

## 유지 요령

- 원본은 고치지 않습니다. 고쳐야 하면 작업으로 복사해서 고치세요.
- 작업 파일은 덮어쓰지 말고 v번호를 올리며 저장하면 되돌아가기 쉽습니다.
- 파일이 큰 작업은 백업에서 원본과 작업을 먼저 챙깁니다.

## 이럴 땐 다른 스타일을

- 사진·영상을 날짜별로만 쌓는다면 → **사진·영상 보관**
- 고객에게 납품하는 일이라면 → **고객·프로젝트 업무**
