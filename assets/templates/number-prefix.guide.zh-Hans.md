# 加编号和日期 使用方法

> 最简单的整理方法。文件夹前加编号，顺序就总是固定；文件名以日期开头，按名称排序就是按日期排序。

| 文件夹 | 放什么 |
|---|---|
| **00_收件箱** | 先放这里。收到的文件、还没决定放哪里的东西（在最上面，总是一眼可见） |
| **01_进行中** | 正在做的事 |
| **02_资料** | 常看的参考资料 |
| **03_已完成** | 已完成但偶尔会看的 |
| **99_归档** | 很旧、几乎不看的（99 号，总在最下面） |

## 收件箱的用法

1. 新文件别多想，先放进 **00_收件箱**。
2. 每周一次，清空 00_收件箱，把文件分到 01～03。
3. 清空就完成了！关键是不让它越堆越多。

## 文件名

像 `2026-11-19_报告.docx` 这样按 **日期_内容** 命名，只要按名称排序就会按日期排好。

## 这些情况适合其他风格

- 想把进行中的事和持续负责的事分开 → **PARA**
- 文件夹非常多，想用编号直接找到 → **Johnny.Decimal**
- 照片、扫描件这类日期就是一切的资料 → **按日期归档**
