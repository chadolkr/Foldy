# 業務分類体系 (ISO 15489) の使い方

> 記録管理の国際規格 ISO 15489 がすすめる「業務分類体系」です。人や部署ではなく、組織が **する仕事** で分けます。大きな仕事 (機能) → その中の仕事 (活動) → 一つの案件、の三段階です。部署が変わってもフォルダーはそのままなので、会社・機関の共有ドライブに向いています。

## フォルダーごとに何を入れるか

| 段階 | 意味 | 例 |
|---|---|---|
| **機能** (01〜09 フォルダー) | 組織が担う大きな仕事 | 02_財務、03_人事 |
| **活動** (機能の中のフォルダー) | その機能をなす仕事 | 02_財務/予算・決算 |
| **案件** (活動の中のフォルダー) | 一回の仕事、いちばん小さな単位 | 02_財務/予算・決算/2026_年間予算 |

| 機能フォルダー | 入れるもの |
|---|---|
| **01_戦略・企画** | 経営計画、目標、取締役会・委員会 |
| **02_財務** | 予算、会計、税金、監査 |
| **03_人事** | 採用、勤務、給与、研修 |
| **04_購買・契約** | 見積、契約、発注、取引先 |
| **05_施設・設備** | オフィス、設備、車両、物品 |
| **06_情報・IT** | システム、アカウント、セキュリティ、記録管理 |
| **07_法務** | 法律確認、訴訟、規程、許認可 |
| **08_渉外・広報** | 広報、顧客、報道、イベント |
| **09_中核業務** | 自分の組織ならではの本業 (営業、生産、研究など) |

01〜08 はたいていの組織にある仕事です (オーストラリア国立公文書館の共通機能の一覧をやさしく縮めました)。自分の組織がしない仕事は消してください。

## ツリーの例

```
わが社/
├─ 02_財務/
│  ├─ 予算・決算/
│  │  └─ 2026_年間予算/
│  └─ 税務/
├─ 04_購買・契約/
│  └─ 2026_事務所移転/
└─ 09_中核業務/
   └─ 営業/
```

## 名前の付け方

| 対象 | ルール | 例 |
|---|---|---|
| 案件フォルダー | 年_案件名 | `2026_事務所移転` |
| ファイル | 日付_内容 | `2026-11-24_賃貸借契約書.pdf` |

## 整理を続けるコツ

- フォルダー名に人や部署の名前を使いません。「田中さんのフォルダー」ではなく「04_購買・契約」。
- 深さは 機能 → 活動 → 案件 の三段階までにします。もっと分けたいときは名前を詳しく書きます。
- 長く残すべき記録 (契約書・会計帳簿) は保存期間を決めておき、過ぎたら整理します。

## こんなときは別のスタイルを

- 一人で使う文書なら → **PARA**
- プロジェクトごとに分ける仕事なら → **プロジェクト管理 (PMBOK 5 段階)**

出典: ISO 15489-1:2016 (記録管理)、オーストラリア国立公文書館 "Classifying information"、https://www.naa.gov.au/information-management/describe-information/classifying-information
