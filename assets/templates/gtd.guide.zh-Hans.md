# GTD 使用方法

> 出自 David Allen 的书《Getting Things Done》（中文版《搞定》，2001 年，2015 年修订）的工作整理法。不要把事情记在脑子里：先把所有东西收集到一处，再逐个问"有没有要做的事？"来分类。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **0_收件箱** | 新收到的文件、下载、扫描的纸张。先全部放这里 | 要长期保存的东西（经常清空） |
| **1_下一步行动** | 马上就能做的事要用的资料。例：要填写的申请表 | 需要好几步的工作 |
| **2_项目** | 需要不止一步的事，每件一个文件夹。例：完成搬家 | 已完成的工作（删除或移到参考资料） |
| **3_等待中** | 交给别人或在等回复的事的资料。例：已发出的报价请求 | 自己要做的事 |
| **4_将来-也许** | 现在不做，但以后也许会做的事。例：想学的东西、旅行计划 | 本周要做的事 |
| **5_参考资料** | 无需行动但还会再看的资料。按主题建文件夹，按名称排序 | 还有事要做的资料 |

有固定日期的事写在日历（日程应用）里，不放文件夹。

## 示例树

```
0_收件箱/
1_下一步行动/
2_项目/
├─ 更新护照/
└─ 完成搬家/
3_等待中/
4_将来-也许/
5_参考资料/
├─ 保险/
└─ 汽车/
```

## 命名规则

| 对象 | 规则 | 示例 |
|---|---|---|
| 项目文件夹 | 用想达成的结果命名 | `更新护照` |
| 文件 | 日期_内容 | `2026-11-24_保险续保通知.pdf` |

## 保持整洁的诀窍

- 经常清空 0_收件箱。逐个打开：两分钟内能做完就马上做，否则移到合适的文件夹或删除。
- 每周对所有文件夹做一次"周回顾"。整理已完成的项目，从 4_将来-也许 中取出想开始的事。
- 5_参考资料 的主题文件夹按名称排序最好找。

## 这些情况适合其他风格

- 比起跟进行动，更看重保存资料 → **PARA**
- 想用编号固定位置 → **Johnny.Decimal**
