# 生活与家庭文件 使用方法

> 把一年只找几次的文件分成“六个格子”。目标是急需时三次点击内就能找到。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **财务** | 纳税申报、存折和银行卡流水、年度汇算 | 所有日常小票 |
| **健康** | 就诊和处方记录、体检结果 | — |
| **住房** | 合同和产权登记、水电煤和物业费、家电说明书 | — |
| **车辆** | 行驶证、保养记录、投保证明 | — |
| **护照与证件** | 护照、身份证、证明文件的复印件 | 原件实物 |
| **保险** | 保单、条款、理赔记录 | — |

## 示例树

```
生活文件/
├─ 财务/
│  ├─ 税务/
│  └─ 存折与银行卡/
├─ 健康/
│  ├─ 就诊与处方/
│  └─ 体检/
├─ 住房/
│  ├─ 合同与产权登记/
│  ├─ 水电煤与物业费/
│  └─ 维修与说明书/
├─ 车辆/
├─ 护照与证件/
└─ 保险/
```

## 命名规则

按 日期_机构_内容 的顺序。日期使用文件上写的日期。

| 对象 | 规则 | 例子 |
|---|---|---|
| 文件 | 日期_机构_内容 | `2026-05-31_税务局_个税申报.pdf` |

## 保持整洁的诀窍

- 护照与证件、保险这类敏感文件，请放在加密的文件夹或带密码的备份中。上传到云端时尤其要小心。
- 有到期日的文件（护照、保险），在文件名或日历中同时记下到期日。
- 超过五年不再需要的文件，请自己确认后再整理。Foldy 不会删除任何东西。

## 这些情况适合其他风格

- 工作和学习资料比文件多 → **PARA**
- 只想按日期堆放 → **按日期归档**
