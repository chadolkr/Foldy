# PARA の使い方

> すべての資料を「いつ終わるか」で 4 つの区分のどれかに入れます。区分が 4 つだけなので、どこに置くか迷う時間が短くなります。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの | 入れないもの |
|---|---|---|
| **1_Projects** | 締め切りや完了の時期がある仕事。例: 引っ越しの準備、第 3 四半期の報告書、パスポートの更新 | 終わりのない仕事 (それは Areas) |
| **2_Areas** | 終わらずに続けて責任を持つ領域。例: 健康、家計、車、チーム運営 | 一度で終わる仕事 |
| **3_Resources** | テーマ別の参考資料。例: レシピ、デザインの参考、マニュアル | 自分が責任を持つ仕事の文書 |
| **4_Archives** | 終わったもの、もう使わないもの。上の 3 つから移してきたフォルダー | いま使っている資料 |

どこに置くか迷ったら、この順で考えてください。

1. **いつ終わる?** 日付があれば → 1_Projects
2. **ずっと受け持つ?** 終わりなく管理するなら → 2_Areas
3. **ただの参考?** → 3_Resources
4. どれでもなく、もう使わないなら → 4_Archives

## ツリーの例

```
ドキュメント/
├─ 1_Projects/
│  ├─ 2026-11_引っ越し/
│  └─ 2026-12_年末調整/
├─ 2_Areas/
│  ├─ 健康/
│  └─ 家計/
├─ 3_Resources/
│  └─ 料理/
└─ 4_Archives/
   └─ 2026-03_パスポート更新/
```

## 名前の付け方

- パターン: `日付_テーマ_内容[_vバージョン].拡張子`
- 例: `2026-11-18_引っ越し_見積比較_v02.xlsx`、`2026-03-02_健康診断_結果.pdf`
- プロジェクト フォルダーの名前を `開始年月_名前` (2026-11_引っ越し) にすると開始順に並びます。
- バージョンは `_v01`、`_v02` のように 2 桁。「最終」「本当の最終」は使いません。

## 整理を続けるコツ

- プロジェクトが終わったら、そのフォルダーを **まるごと** 4_Archives に移します。消しません。
- 月に 1 回 1_Projects を見て、終わった仕事を保管に移します。
- 2_Areas はあまり変わりません。領域が 10 個を超えたら、細かく分けすぎていないか見直してください。
- サブフォルダーは 2〜3 段階までにすると探しやすくなります。

## こんなときは別のスタイルを

- 資料がとても多く、番号ですぐ探したい → **Johnny.Decimal**
- 顧客ごとに仕事が分かれる外注・営業 → **顧客・プロジェクト業務**
- ほとんどが写真・動画 → **写真・動画の保管**
