# GTD の使い方

> デビッド・アレンの本『Getting Things Done』(邦題『はじめての GTD ストレスフリーの整理術』、2001 年・改訂版 2015 年) の仕事術です。頭の中に置いておかず、まず一か所に集めてから「やることはあるか?」で一つずつ分けます。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの | 入れないもの |
|---|---|---|
| **0_インボックス** | 新しく受け取ったファイル、ダウンロード、スキャンした紙。まずここへ | 長く置くもの (こまめに空にする) |
| **1_次にとる行動** | すぐできる行動に使う資料。例: 書く申込書 | 何段階も要る仕事 |
| **2_プロジェクト** | 二つ以上の行動が要ること、ひとつごとにフォルダー一つ。例: 引っ越しを終える | 終わった仕事 (消すか資料へ) |
| **3_連絡待ち** | 人に任せたことや返事を待っていることの資料。例: 送った見積依頼 | 自分がすること |
| **4_いつかやる・多分やる** | 今ではないが、いつかやるかもしれないこと。例: 学びたいこと、旅行の計画 | 今週やること |
| **5_資料** | 行動は要らないが、また見る資料。テーマごとにフォルダーを作り名前順に | 行動が残っている資料 |

日付が決まっていることはフォルダーではなくカレンダー (予定アプリ) に書きます。

## ツリーの例

```
0_インボックス/
1_次にとる行動/
2_プロジェクト/
├─ パスポートを更新する/
└─ 引っ越しを終える/
3_連絡待ち/
4_いつかやる・多分やる/
5_資料/
├─ 保険/
└─ 車/
```

## 名前の付け方

| 対象 | ルール | 例 |
|---|---|---|
| プロジェクトのフォルダー | 達成したい結果で | `パスポートを更新する` |
| ファイル | 日付_内容 | `2026-11-24_保険更新のお知らせ.pdf` |

## 整理を続けるコツ

- 0_インボックス はこまめに空にします。一つずつ開いて 2 分で終わるならすぐやり、そうでなければ合うフォルダーへ移すか削除します。
- 週に一度、すべてのフォルダーを見直す「週次レビュー」をします。終わったプロジェクトを片付け、4_いつかやる・多分やる から始めたいものを取り出します。
- 5_資料 のテーマフォルダーは名前順に並べると探しやすくなります。

## こんなときは別のスタイルを

- 行動より資料の保管が中心なら → **PARA**
- 番号で置き場所を決めたいなら → **Johnny.Decimal**

出典: David Allen, *Getting Things Done* (Penguin, 2015), https://gettingthingsdone.com/
