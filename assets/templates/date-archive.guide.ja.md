# 日付別の保管庫の使い方

> どこに入れるか迷わない方式です。ファイルができた日の 年-月 フォルダーに入れるだけです。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの | 入れないもの |
|---|---|---|
| **年 (2026)** | その年の 年-月 フォルダー | ファイルを直接は入れません |
| **年-月 (2026-11)** | その月にできた・受け取ったファイル | 長く直しながら使う作業ファイル |

テーマで探す資料より、過ぎたらあまり見返さない記録 (領収書、請求書、スクリーンショット、受け取ったファイル) に向いています。

## ツリーの例

```
保管庫/
└─ 2026/
   ├─ 2026-10/
   └─ 2026-11/
      ├─ 2026-11-03_議事録.md
      └─ 2026-11-18_電気料金.pdf
```

## 名前の付け方

日付_内容 の順で名付けます。名前順の並べ替えがそのまま時間順になります。

| 対象 | ルール | 例 |
|---|---|---|
| ファイル | YYYY-MM-DD_内容 | `2026-11-18_電気料金.pdf` |
| フォルダー | YYYY-MM | `2026-11` |

## 整理を続けるコツ

- 月が変わったら新しい 年-月 フォルダーを作ります。このテンプレートを同じ保管庫にもう一度使うと、ないフォルダーだけを作ります。
- 日付は「できた日」にそろえてください。受け取った日と書いた日が混ざると分かりにくくなります。
- フォルダー整理の「日付別」で、すでにたまったファイルをこの構成に移すこともできます。

## こんなときは別のスタイルを

- プロジェクトやテーマで探したい → **PARA** または **Johnny.Decimal**
- 写真・動画 → **写真・動画の保管** (日付_行事名 + RAW を分ける)
