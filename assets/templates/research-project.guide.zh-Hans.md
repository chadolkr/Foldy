# 研究与学习项目 使用方法

> 按 阅读（文献）→ 收集（数据）→ 分析 → 撰写（稿件）→ 演示 的流程划分格子。适合论文、毕业设计和学习笔记。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **文献** | 论文 PDF、参考文献列表（.bib）、阅读笔记 | 自己写的稿件 |
| **数据/原件** | 收到或采集的原始数据 | 修改过的数据 |
| **数据/清洗后** | 整理和加工后的数据 | 原始数据 |
| **分析** | 分析代码和笔记本、结果表格和图表 | 原始数据 |
| **稿件** | 论文和报告稿件及其版本 | 演示资料 |
| **演示** | 幻灯片、海报 | 稿件 |

## 示例树

```
传感器研究/
├─ 文献/
├─ 数据/
│  ├─ 原件/
│  └─ 清洗后/
├─ 分析/
├─ 稿件/
├─ 演示/
└─ README.md
```

## 命名规则

| 对象 | 规则 | 例子 |
|---|---|---|
| 论文 | 作者_年份_标题 | `Lee_2023_传感器_融合.pdf` |
| 数据 | 内容_日期 | `问卷_2026-11-18.csv` |
| 稿件、分析 | 名称_v版本 | `稿件_v0.3.docx` |

## 保持整洁的诀窍

- 绝不修改原始数据。加工在清洗后文件夹中进行，加工方法以代码形式留在分析文件夹中。
- 读过的论文在 README 或文献笔记中写一句话摘要，以后引用更方便。

## 这些情况适合其他风格

- 只管理一份文档的草稿、审阅和最终版 → **文档编写阶段**
- 重点是系统开发而不是研究 → **IT 系统开发文档**
