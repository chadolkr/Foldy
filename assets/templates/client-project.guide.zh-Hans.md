# 客户与项目工作 使用方法

> 在客户文件夹下按开始日期排列项目，项目内部按工作顺序（合同 → 资料 → 工作 → 交付物）编号。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **客户名称/** | 该客户的项目文件夹 | 混合多个客户的资料 |
| **日期_项目/** | 一个项目的全部内容。日期为开始日期 | — |
| **01_合同** | 合同、报价单、订单、保密协议、发票 | 正在写的草稿 |
| **02_资料** | 客户提供的原始资料（不修改） | 你修改过的文件 |
| **03_工作** | 草稿、工作文件、会议备忘 | 已发出的最终版 |
| **04_交付物** | 只放发给客户的最终版 | 草稿和中间版本 |
| **99_归档** | 结束后要保留的、不再使用的 | — |

## 示例树

```
ACME/
└─ 2026-11-18_官网改版/
   ├─ 01_合同/
   │  └─ 2026-12-01_ACME_合同_签字版.pdf
   ├─ 02_资料/
   ├─ 03_工作/
   ├─ 04_交付物/
   │  └─ 2026-12-20_ACME_设计稿_v03.pdf
   └─ 99_归档/
```

## 命名规则

- 格式：`日期_客户_文档类型_v版本.扩展名`
- 例如：`2026-11-18_ACME_提案书_v03.pptx`、`2026-12-01_ACME_合同_签字版.pdf`
- 不在文件名后加 `_final` 或“最终”，而是用 **日期**。日期最新的就是最新版。
- 版本从 `_v01` 开始，用两位数。

## 保持整洁的诀窍

- 最终版 **只放在 04_交付物**。不要在别处保存同一文件的副本。
- 02_资料 中的原件不要修改，需要改时复制到 03_工作 再改。
- 项目结束后，保留在客户文件夹中，或只把需要整理的移到 99_归档。
- 客户名称统一一种写法（不要 ACME 和 艾克米 混用）。

## 这些情况适合其他风格

- 个人事务和工作混在一起，不按客户区分 → **PARA**
- 开发软件的项目 → **IT 系统开发文档**
