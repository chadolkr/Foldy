# 날짜별 보관함 사용법

> 어디에 넣을지 고민하지 않는 방식입니다. 파일이 생긴 날짜의 연-월 폴더에 넣기만 하면 됩니다.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 | 넣지 않는 것 |
|---|---|---|
| **연도 (2026)** | 그해의 연-월 폴더들 | 파일을 바로 넣지 않습니다 |
| **연-월 (2026-11)** | 그달에 생기거나 받은 파일 | 오래 두고 고쳐 쓰는 작업 파일 |

주제별로 찾아야 하는 자료보다, 지나가면 다시 볼 일이 적은 기록(영수증, 고지서, 캡처, 받은 파일)에 알맞습니다.

## 예시 트리

```
보관함/
└─ 2026/
   ├─ 2026-10/
   └─ 2026-11/
      ├─ 2026-11-03_회의록.md
      └─ 2026-11-18_전기요금.pdf
```

## 이름 규칙

날짜_내용 순서로 이름 붙입니다. 이름순 정렬이 곧 시간순이 됩니다.

| 대상 | 규칙 | 예 |
|---|---|---|
| 파일 | YYYY-MM-DD_내용 | `2026-11-18_전기요금.pdf` |
| 폴더 | YYYY-MM | `2026-11` |

## 유지 요령

- 달이 바뀌면 새 연-월 폴더를 만듭니다. 이 템플릿을 같은 보관함에 다시 쓰면 없는 폴더만 만들어 줍니다.
- 날짜는 "생긴 날"로 통일하세요. 어떤 건 받은 날, 어떤 건 쓴 날로 하면 섞입니다.
- 폴더 정리의 "날짜별" 방식으로 이미 쌓인 파일을 이 구조로 옮길 수도 있습니다.

## 이럴 땐 다른 스타일을

- 프로젝트·주제로 찾아야 한다면 → **PARA** 또는 **Johnny.Decimal**
- 사진·영상이라면 → **사진·영상 보관** (날짜_행사명 + RAW 구분)
