# PARA 使用方法

> 按“什么时候结束”把所有资料放进四个格子之一。只有四个格子，决定放哪里的时间很短。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **1_Projects** | 有截止或完成时间的事。例如：准备搬家、第三季度报告、更新护照 | 没有终点的事（那是 Areas） |
| **2_Areas** | 不会结束、持续负责的领域。例如：健康、财务、汽车、团队管理 | 做一次就结束的事 |
| **3_Resources** | 按主题分的参考资料。例如：菜谱、设计参考、使用手册 | 你负责之事的文档 |
| **4_Archives** | 已结束或不再使用的。从上面三格移过来的文件夹 | 正在使用的资料 |

不确定放哪里时，按这个顺序问自己：

1. **什么时候结束？** 有日期 → 1_Projects
2. **会一直负责吗？** 需要一直管理 → 2_Areas
3. **只是参考吗？** → 3_Resources
4. 都不是且不再使用 → 4_Archives

## 示例树

```
文档/
├─ 1_Projects/
│  ├─ 2026-11_搬家/
│  └─ 2026-12_年度汇算/
├─ 2_Areas/
│  ├─ 健康/
│  └─ 财务/
├─ 3_Resources/
│  └─ 烹饪/
└─ 4_Archives/
   └─ 2026-03_更新护照/
```

## 命名规则

- 格式：`日期_主题_内容[_v版本].扩展名`
- 例如：`2026-11-18_搬家_报价比较_v02.xlsx`、`2026-03-02_体检_结果.pdf`
- 项目文件夹命名为 `开始年月_名称`（2026-11_搬家），就会按开始时间排序。
- 版本用两位数，如 `_v01`、`_v02`。不用“最终版”“真最终版”。

## 保持整洁的诀窍

- 项目结束后，把它的文件夹 **整个** 移到 4_Archives。不要删除。
- 每月看一遍 1_Projects，把已完成的转入归档。
- 2_Areas 很少变化。如果领域超过 10 个，检查一下是不是分得太细了。
- 子文件夹控制在 2～3 层以内更容易查找。

## 这些情况适合其他风格

- 资料非常多，想用编号直接找到 → **Johnny.Decimal**
- 按客户划分的外包、销售工作 → **客户与项目工作**
- 大部分是照片和视频 → **照片与视频归档**
