# 建設・設計の情報管理 (ISO 19650 CDE) の使い方

> 建設情報管理の国際標準 ISO 19650 の共通データ環境 (CDE) の 4 つの状態 (作業中 → 共有 → 発行 → 保管) で、図面・モデル・文書を分けます。いまそのファイルがどの状態かがフォルダーですぐ分かります。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの |
|---|---|
| **01_作業中** (WIP) | チームで直している途中のもの。チームの外からは見ません |
| **02_共有** (Shared) | 他分野・他チームとの協議・レビューのために出したもの |
| **03_発行** (Published) | 承認済みで現場・発注者が使ってよい最終版 |
| **04_保管** (Archived) | 新しい改訂で差し替えられたか、終わったもの。記録として残します |

## 名前の付け方

- パターン: `プロジェクト_分野_文書種類_番号_改訂.拡張子` (例: `顧客センター新築_建築_平面図_A101_P02.pdf`)
- 改訂の表記は会社・発注者のルールに従ってください (例: レビュー用 P01、施工用 C01)。

## 整理を続けるコツ

- 状態を移すときは決めたレビュー・承認を通します。01 から直接 03 へは行きません。
- 発行版は直しません。直すときは 01_作業中 で新しい改訂を作ります。

## こんなときは別のスタイルを

- 図面のない一般の業務プロジェクト → **プロジェクト管理 (PMBOK 5 段階)**
