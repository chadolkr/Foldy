# 建设与设计信息管理（ISO 19650 CDE）使用方法

> 按建设信息管理国际标准 ISO 19650 公共数据环境（CDE）的四种状态（进行中 → 共享 → 发布 → 归档）划分图纸、模型和文档。文件当前处于哪种状态，看文件夹就一目了然。

## 每个文件夹放什么

| 文件夹 | 放什么 |
|---|---|
| **01_进行中**（WIP） | 团队正在修改的内容。团队外不查看 |
| **02_共享**（Shared） | 提供给其他专业和团队协调、审查的内容 |
| **03_发布**（Published） | 已批准、现场或业主可以使用的最终版 |
| **04_归档**（Archived） | 被新版次替换或已结束的。作为记录保留 |

## 命名规则

- 格式：`项目_专业_文档类型_编号_版次.扩展名`（例如 `客服中心新建_建筑_平面图_A101_P02.pdf`）
- 版次标注请遵循公司或业主的规定（例如审查用 P01、施工用 C01）。

## 保持整洁的诀窍

- 状态之间移动要经过约定的审查和批准。不能从 01 直接到 03。
- 不修改已发布的版本。需要修改时在 01_进行中 中创建新版次。

## 这些情况适合其他风格

- 没有图纸的一般工作项目 → **项目管理（PMBOK 5 阶段）**
