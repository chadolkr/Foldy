# How to use Business classification (ISO 15489)

> The "business classification scheme" recommended by ISO 15489, the international standard for records management. You split by **what the organization does**, not by people or departments: big job (function) → the work inside it (activity) → one single case (transaction). Folders stay the same when departments change, so it suits company or agency shared drives.

## What goes in each folder

| Level | Meaning | Example |
|---|---|---|
| **Function** (folders 01–09) | A big responsibility of the organization | 02_Financial management, 03_Personnel |
| **Activity** (folders inside a function) | The work that makes up that function | 02_Financial management/Budget and closing |
| **Transaction** (folders inside an activity) | One single piece of work, the smallest unit | 02_Financial management/Budget and closing/2026_Annual budget |

| Function folder | What goes in |
|---|---|
| **01_Strategic management** | Business plans, goals, board and committee meetings |
| **02_Financial management** | Budget, accounting, tax, audit |
| **03_Personnel** | Recruitment, attendance, payroll, training |
| **04_Procurement** | Quotes, contracts, orders, suppliers |
| **05_Property and equipment** | Offices, equipment, vehicles, supplies |
| **06_Information and IT** | Systems, accounts, security, records management |
| **07_Legal** | Legal review, lawsuits, regulations, permits |
| **08_External relations** | Publicity, customers, press, events |
| **09_Core business** | What your organization is actually for (sales, production, research …) |

01–08 exist in almost every organization (a simplified version of the National Archives of Australia's list of common functions). Delete the ones your organization doesn't do.

## Example tree

```
Our company/
├─ 02_Financial management/
│  ├─ Budget and closing/
│  │  └─ 2026_Annual budget/
│  └─ Tax/
├─ 04_Procurement/
│  └─ 2026_Office move/
└─ 09_Core business/
   └─ Sales/
```

## Naming rules

| What | Rule | Example |
|---|---|---|
| Transaction folders | year_name | `2026_Office move` |
| Files | date_content | `2026-11-24_Lease agreement.pdf` |

## Keeping it tidy

- Don't use people's or departments' names in folder names. Use "04_Procurement", not "Kim's folder".
- Don't go deeper than function → activity → transaction. If you want more detail, write a more specific name.
- Records you must keep for a long time (contracts, accounts) get a retention period; clear them out once it has passed.

## When another style fits better

- Documents only you use → **PARA**
- Work split by project → **Project management (PMBOK 5 phases)**

Source: ISO 15489-1:2016 (Records management); National Archives of Australia, "Classifying information", https://www.naa.gov.au/information-management/describe-information/classifying-information
