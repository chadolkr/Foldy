# GTD 사용법

> 데이비드 앨런의 책 《Getting Things Done》(2001, 개정판 2015)에 나오는 일 정리법입니다. 머릿속에 담아 두지 말고 일단 한곳에 모은 뒤, "할 일이 있나?"로 하나씩 나눕니다.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 | 넣지 않는 것 |
|---|---|---|
| **0_받은 것** | 새로 받은 파일, 다운로드, 스캔한 종이. 일단 여기로 | 오래 둘 것 (자주 비우기) |
| **1_다음 할 일** | 바로 할 수 있는 일에 쓰는 자료. 예: 작성할 신청서 | 여러 단계가 필요한 일 |
| **2_프로젝트** | 두 단계 넘게 걸리는 일. 일마다 폴더 하나. 예: 이사 마치기 | 끝난 일 (지우거나 참고 자료로) |
| **3_기다리는 중** | 남에게 맡겼거나 답을 기다리는 일의 자료. 예: 보낸 견적 요청 | 내가 할 일 |
| **4_언젠가** | 지금은 아니지만 나중에 할지도 모르는 것. 예: 배우고 싶은 것, 여행 계획 | 이번 주에 할 일 |
| **5_참고 자료** | 할 일은 없지만 다시 볼 자료. 주제별로 폴더를 만들어 이름순으로 | 할 일이 남은 자료 |

날짜가 정해진 일은 폴더가 아니라 달력(일정 앱)에 적습니다.

## 예시 트리

```
0_받은 것/
1_다음 할 일/
2_프로젝트/
├─ 여권 갱신하기/
└─ 이사 마치기/
3_기다리는 중/
4_언젠가/
5_참고 자료/
├─ 보험/
└─ 자동차/
```

## 이름 규칙

| 대상 | 규칙 | 예 |
|---|---|---|
| 프로젝트 폴더 | 이루고 싶은 결과로 | `여권 갱신하기` |
| 파일 | 날짜_내용 | `2026-11-24_보험 갱신 안내.pdf` |

## 유지 요령

- 0_받은 것은 자주 비웁니다. 하나씩 열어 2분 안에 끝나면 바로 하고, 아니면 알맞은 폴더로 옮기거나 지웁니다.
- 일주일에 한 번 모든 폴더를 훑어보는 "주간 검토"를 합니다. 끝난 프로젝트는 정리하고, 4_언젠가에서 이번에 할 것을 꺼냅니다.
- 5_참고 자료는 주제 폴더를 이름순으로 두면 찾기 쉽습니다.

## 이럴 땐 다른 스타일을

- 할 일보다 자료 보관이 중심이라면 → **PARA**
- 번호로 자리를 정하고 싶다면 → **Johnny.Decimal**
