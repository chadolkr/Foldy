# 고객·프로젝트 업무 사용법

> 고객 폴더 아래 프로젝트를 시작일순으로 두고, 안쪽은 일의 순서(계약 → 자료 → 작업 → 산출물)대로 번호를 붙입니다.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 | 넣지 않는 것 |
|---|---|---|
| **고객 이름/** | 그 고객의 프로젝트 폴더들 | 여러 고객이 섞인 자료 |
| **날짜_프로젝트/** | 프로젝트 하나의 모든 것. 날짜는 시작일 | — |
| **01_계약** | 계약서, 견적서, 발주서, NDA, 세금계산서 | 작업 중인 초안 |
| **02_자료** | 고객에게 받은 원본 자료 (고치지 않음) | 내가 고친 파일 |
| **03_작업** | 초안, 작업 파일, 회의 메모 | 보낸 최종본 |
| **04_산출물** | 고객에게 보낸 최종본만 | 초안·중간본 |
| **99_보관** | 끝난 뒤 남길 것, 더는 안 쓰는 것 | — |

## 예시 트리

```
ACME/
└─ 2026-11-18_홈페이지개편/
   ├─ 01_계약/
   │  └─ 2026-11-18_ACME_계약서_서명본.pdf
   ├─ 02_자료/
   ├─ 03_작업/
   ├─ 04_산출물/
   │  └─ 2026-12-20_ACME_디자인시안_v03.pdf
   └─ 99_보관/
```

## 이름 규칙

- 패턴: `날짜_고객_문서종류_v버전.확장자`
- 예: `2026-11-18_ACME_제안서_v03.pptx`, `2026-12-01_ACME_계약서_서명본.pdf`
- 파일명에 `_final`, `최종`을 붙이는 대신 **날짜**를 씁니다. 가장 최근 날짜가 최신본입니다.
- 버전은 `_v01`부터 두 자리로.

## 유지 요령

- 최종본은 **04_산출물에만** 둡니다. 다른 곳에 같은 파일을 복사해 두지 않습니다.
- 02_자료의 원본은 고치지 말고, 고칠 때는 03_작업에 복사해서 고칩니다.
- 프로젝트가 끝나면 고객 폴더 안에서 그대로 두거나, 정리할 것만 99_보관으로 옮깁니다.
- 고객 이름은 한 가지 표기로 통일합니다 (ACME, 에이씨엠이 섞이지 않게).

## 이럴 땐 다른 스타일을

- 고객 구분 없이 개인 일과 업무가 섞여 있다면 → **PARA**
- 소프트웨어를 만드는 프로젝트라면 → **IT 시스템 개발 문서**
