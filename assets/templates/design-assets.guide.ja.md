# デザイン・制作アセットの使い方

> 触ってはいけないもの (元データ)、作っている途中のもの (作業)、成果物 (書き出し)、ひらめき (参考) を混ぜない 4 つの区分です。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの | 入れないもの |
|---|---|---|
| **元データ** | 受け取った画像・写真・素材、フォント | 直したファイル |
| **作業** | 作業ファイル (psd、ai、fig、プロジェクト ファイル) とバージョン | 完成版 |
| **書き出し** | 納品・公開用に書き出した結果 (png、jpg、pdf、mp4) | 作業中のファイル |
| **参考** | リファレンス、ムードボード、ガイドライン | 自分が作った成果 |

## ツリーの例

```
ブランドロゴ/
├─ 元データ/
├─ 作業/
│  ├─ ロゴ_メイン_v2.ai
│  └─ ロゴ_メイン_v3.ai
├─ 書き出し/
│  ├─ ロゴ_Web_512.png
│  └─ ロゴ_印刷.pdf
└─ 参考/
```

## 名前の付け方

| 対象 | ルール | 例 |
|---|---|---|
| 作業ファイル | 作業名_内容_vバージョン | `ロゴ_メイン_v3.ai` |
| 書き出したファイル | 作業名_用途_サイズ | `ロゴ_Web_512.png` |

## 整理を続けるコツ

- 元データは直しません。直す必要があれば作業にコピーして直してください。
- 作業ファイルは上書きせず、v 番号を上げながら保存すると戻りやすくなります。
- ファイルの大きい作業は、バックアップで元データと作業を先に確保します。

## こんなときは別のスタイルを

- 写真・動画を日付順にためるだけ → **写真・動画の保管**
- 顧客に納品する仕事 → **顧客・プロジェクト業務**
