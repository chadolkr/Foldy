# 文档编写阶段 使用方法

> 按一份文档经历的阶段划分文件夹。只看文件夹就知道“现在进行到哪一步了”。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **01_草稿** | 正在撰写的文件及其各版本 | 要发给别人的文件 |
| **02_审阅** | 正在审阅的文件、收到的反馈 | 仍在撰写的草稿 |
| **03_最终** | 一份已定稿的最终版 | 多个版本 |
| **04_分发** | 实际发出的文件（PDF 等）及发出日期 | 要修改的文件 |

## 示例树

```
商业计划书/
├─ 01_草稿/
│  ├─ 商业计划书_v0.1_草稿.docx
│  └─ 商业计划书_v0.2_草稿.docx
├─ 02_审阅/
├─ 03_最终/
│  └─ 商业计划书_v1.0_最终_2026-11-18.docx
├─ 04_分发/
│  └─ 2026-11-18_商业计划书_投资方.pdf
└─ README.md
```

## 命名规则

| 对象 | 规则 | 例子 |
|---|---|---|
| 工作文件 | 文档名_v版本_状态 | `商业计划书_v0.2_草稿.docx` |
| 最终版 | 文档名_v版本_最终_日期 | `商业计划书_v1.0_最终_2026-11-18.docx` |
| 分发版 | 日期_文档名_接收方 | `2026-11-18_商业计划书_投资方.pdf` |

## 保持整洁的诀窍

- 进入下一阶段时 **复制** 文件。删除前一阶段的文件就无法回退。
- 不要写“最终_真最终”，而是提高版本号。
- 03_最终 中始终只放一个文件。

## 这些情况适合其他风格

- 按客户处理多个项目 → **客户与项目工作**
- 撰写论文、报告并配合资料和数据 → **研究与学习项目**
