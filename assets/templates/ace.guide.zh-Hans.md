# ACE 使用方法

> Nick Milo（Linking Your Thinking）提出的三格整理法。按你想对它做什么来分：想理解就放 Atlas，想按日期回看就放 Calendar，想去行动就放 Efforts。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **Atlas** | 学到和收集的知识 | 日期很重要的记录 |
| **Atlas/Cards** | 用自己的话整理想法和概念的笔记 | 别人写的原文 |
| **Atlas/Sources** | 书、文章、视频等来源资料及其摘要 | 自己的待办 |
| **Calendar** | 带日期的记录：会议纪要、日志、当天的笔记 | 与日期无关的知识 |
| **Efforts** | 正在做的事和项目，每件一个文件夹 | 已完成且不会再看的东西 |

## 示例树

```
Atlas/
├─ Cards/
│  └─ 养成好习惯.md
└─ Sources/
   └─ 掌控习惯 摘要.md
Calendar/
└─ 2026-11-24_周会.md
Efforts/
└─ 开一个博客/
```

## 命名规则

| 对象 | 规则 | 示例 |
|---|---|---|
| Calendar 记录 | 日期_内容 | `2026-11-24_周会.md` |
| Efforts 文件夹 | 所做之事的名称 | `开一个博客` |

## 保持整洁的诀窍

- 三格的名称保留英文。和别人的说明、示例一致，容易照着做。
- 一开始在 Atlas 里只放 Cards 和 Sources，需要时再增加。
- Efforts 里完成的事，把整个文件夹移到 Atlas 或归档文件夹。

## 这些情况适合其他风格

- 工作文档比笔记多 → **PARA**
- 想管理待办的流程 → **GTD (Getting Things Done)**
