# 照片与视频归档 使用方法

> 按 年份 → 日期_活动名 排列，按名称排序就是按时间排序。原片只放在一个地方，绝不修改。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **年份/** | 当年的活动文件夹 | 混有多个年份的照片 |
| **日期_活动名/** | 一个活动。日期为第一天 | — |
| **RAW** | 从相机、手机导入的原片，原样不动 | 修过的文件 |
| **修图** | 调色、裁剪、合成后的文件 | 原片 |
| **导出** | 为分享或冲印缩小或转换的文件 | 正在处理的文件 |

## 示例树

```
照片/
└─ 2026/
   ├─ 2026-08-02_暑假/
   └─ 2026-11-18_济州旅行/
      ├─ RAW/
      │  └─ 2026-11-18_143205_济州旅行_001.jpg
      ├─ 修图/
      │  └─ 2026-11-18_济州旅行_修图_001.jpg
      └─ 导出/
```

## 命名规则

- 格式：`日期_时间_活动_序号.扩展名`（以拍摄时间为准）
- 例如：`2026-11-18_143205_济州旅行_001.jpg`、`2026-11-18_济州旅行_修图_001.jpg`
- 相机起的名字（IMG_1234）可以用 Foldy 批量重命名中的“按拍摄时间命名”一次改好。

## 保持整洁的诀窍

- **绝不修改 RAW。** 修图总是在修图文件夹中用副本进行。
- 备份只要有 RAW，其余都能重新生成。备份顺序 RAW 优先。
- 活动名要简短。完整路径太长，移到其他设备时会出问题。
- 导入完成当天就挑出模糊或重复的照片，以后会轻松很多（删除前请自己确认）。

## 这些情况适合其他风格

- 照片是文档的一部分（现场照片、凭证）→ **客户与项目工作** 的 02_资料
- 文档比照片多 → **PARA**
