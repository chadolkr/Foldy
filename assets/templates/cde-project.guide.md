# 건설·설계 정보 관리 (ISO 19650 CDE) 사용법

> 건설 정보 관리 국제 표준 ISO 19650의 공통 데이터 환경(CDE) 네 상태(작업 중 → 공유 → 발행 → 보관)대로 도면·모델·문서를 나눕니다. 지금 이 파일이 어떤 상태인지가 폴더로 바로 보여요.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 |
|---|---|
| **01_작업중** (WIP) | 우리 팀이 고치는 중인 것. 팀 밖에서는 보지 않아요 |
| **02_공유** (Shared) | 다른 분야·팀과 협의·검토하려고 내놓은 것 |
| **03_발행** (Published) | 승인받아 현장·발주처가 써도 되는 최종본 |
| **04_보관** (Archived) | 새 개정으로 바뀌었거나 끝난 것. 기록으로 남겨요 |

## 이름 규칙

- 패턴: `프로젝트_분야_문서종류_번호_개정.확장자` (예: `고객센터신축_건축_평면도_A101_P02.pdf`)
- 개정 표기는 회사·발주처 규칙을 따르세요 (예: 검토용 P01, 시공용 C01).

## 유지 요령

- 상태를 옮길 때는 정한 검토·승인을 거쳐요. 01에서 바로 03으로 가지 않아요.
- 발행본은 고치지 않아요. 고칠 때는 01_작업중에서 새 개정을 만들어요.
