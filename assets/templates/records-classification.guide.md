# 업무 분류 체계 (ISO 15489) 사용법

> 기록관리 국제 표준 ISO 15489가 권하는 "업무 분류 체계"입니다. 사람이나 부서가 아니라 조직이 **하는 일**로 나눕니다. 큰 일(기능) → 그 안의 일(활동) → 하나의 건, 세 단계입니다. 부서가 바뀌어도 폴더는 그대로라 회사·기관 공유 드라이브에 맞습니다.

## 폴더별로 무엇을 넣나

| 단계 | 뜻 | 예 |
|---|---|---|
| **기능** (01~09 폴더) | 조직이 맡은 큰 일 | 02_재무, 03_인사 |
| **활동** (기능 안의 폴더) | 그 기능을 이루는 일 | 02_재무/예산·결산 |
| **건** (활동 안의 폴더) | 한 번의 일, 가장 작은 단위 | 02_재무/예산·결산/2026_연간 예산 |

| 기능 폴더 | 넣는 것 |
|---|---|
| **01_전략·기획** | 경영 계획, 목표, 이사회·위원회 회의 |
| **02_재무** | 예산, 회계, 세금, 감사 |
| **03_인사** | 채용, 근무, 급여, 교육 |
| **04_구매·계약** | 견적, 계약, 발주, 거래처 |
| **05_시설·장비** | 사무실, 장비, 차량, 물품 |
| **06_정보·IT** | 시스템, 계정, 보안, 기록 관리 |
| **07_법무** | 법률 검토, 소송, 규정, 인허가 |
| **08_대외 협력** | 홍보, 고객, 언론, 행사 |
| **09_핵심 업무** | 우리 조직만의 본업 (영업, 생산, 연구 등) |

01~08은 어느 조직에나 있는 일입니다(호주 국가기록원의 공통 기능 목록을 쉽게 줄였습니다). 우리 조직이 하지 않는 일은 지우세요.

## 예시 트리

```
우리회사/
├─ 02_재무/
│  ├─ 예산·결산/
│  │  └─ 2026_연간 예산/
│  └─ 세무/
├─ 04_구매·계약/
│  └─ 2026_사무실 이전/
└─ 09_핵심 업무/
   └─ 영업/
```

## 이름 규칙

| 대상 | 규칙 | 예 |
|---|---|---|
| 건 폴더 | 연도_건 이름 | `2026_사무실 이전` |
| 파일 | 날짜_내용 | `2026-11-24_임대차 계약서.pdf` |

## 유지 요령

- 폴더 이름에 사람·부서 이름을 쓰지 않습니다. "김 대리 폴더" 대신 "04_구매·계약".
- 깊이는 기능 → 활동 → 건, 세 단계를 넘기지 않습니다. 더 나누고 싶으면 이름을 자세히 씁니다.
- 오래 둬야 하는 기록(계약서·회계 장부)은 보존 기간을 정해 두고 지나면 정리합니다.

## 이럴 땐 다른 스타일을

- 혼자 쓰는 문서라면 → **PARA**
- 프로젝트별로 나누는 일이라면 → **프로젝트 관리 (PMBOK 5단계)**
