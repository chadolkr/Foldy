# 写真・動画の保管の使い方

> 年 → 日付_行事名 の順に置くと、名前順の並べ替えがそのまま時間順になります。元データは 1 か所にだけ置き、決して直しません。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの | 入れないもの |
|---|---|---|
| **年/** | その年の行事フォルダー | 年が混ざった写真 |
| **日付_行事名/** | 1 つの行事。日付は初日 | — |
| **RAW** | カメラ・スマホから取り込んだ元データそのまま | 補正したファイル |
| **編集版** | 補正・切り抜き・合成したファイル | 元データ |
| **書き出し** | 共有・印刷用に縮めたり変換したりしたファイル | 作業中のファイル |

## ツリーの例

```
写真/
└─ 2026/
   ├─ 2026-08-02_夏休み/
   └─ 2026-11-18_済州旅行/
      ├─ RAW/
      │  └─ 2026-11-18_143205_済州旅行_001.jpg
      ├─ 編集版/
      │  └─ 2026-11-18_済州旅行_編集版_001.jpg
      └─ 書き出し/
```

## 名前の付け方

- パターン: `日付_時刻_行事_連番.拡張子` (撮影時刻基準)
- 例: `2026-11-18_143205_済州旅行_001.jpg`、`2026-11-18_済州旅行_編集版_001.jpg`
- カメラが付けた名前 (IMG_1234) は、Foldy の一括名前変更の「撮影時刻で名前を作る」でまとめて変えられます。

## 整理を続けるコツ

- **RAW は決して直しません。** 補正はいつもコピーを使って編集版で行います。
- バックアップは RAW さえあればほかは作り直せます。バックアップは RAW が先です。
- 行事名は短く。パス全体が長くなると、ほかの機器に移すときに問題が起きます。
- 取り込みを終えた日に、ぶれた写真や重なった写真をすぐ選んでおくと後が楽です (消すのは自分で確かめてから)。

## こんなときは別のスタイルを

- 写真が文書の一部 (現場写真、証拠) → **顧客・プロジェクト業務** の 02_資料
- 写真より文書が多い → **PARA**
