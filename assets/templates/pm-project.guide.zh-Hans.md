# 项目管理（PMBOK 5 阶段）使用方法

> 适用于各行业的项目文档整理方法。按美国项目管理协会（PMI）PMBOK 指南中的五大过程组（启动、规划、执行、监控、收尾）顺序划分文件夹。

## 每个文件夹放什么

| 文件夹 | 放什么 |
|---|---|
| **01_启动** | 项目章程、干系人登记册、启动批准 |
| **02_规划** | 范围、进度（WBS）、预算、质量、风险、沟通计划 |
| **03_执行** | 交付成果、会议记录、工作资料 |
| **04_监控** | 周报和月报、变更请求、问题与风险记录 |
| **05_收尾** | 最终报告、验收确认书、经验教训（复盘）、合同关闭 |
| **99_归档** | 旧版本、不再使用的 |

## 保持整洁的诀窍

- 监控与执行同时持续进行。报告和变更请求随时放进 04。
- 结束时把经验教训留在 05_收尾，下一个项目会轻松很多。

## 这些情况适合其他风格

- 开发软件的项目 → **IT 系统开发文档**
- 多个团队交换图纸和模型的建设与设计 → **建设与设计信息管理**
- 只按客户区分合同和交付物就足够 → **客户与项目工作**
