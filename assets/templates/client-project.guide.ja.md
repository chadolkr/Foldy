# 顧客・プロジェクト業務の使い方

> 顧客フォルダーの下にプロジェクトを開始日順に置き、中は仕事の順番 (契約 → 資料 → 作業 → 成果物) で番号を付けます。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの | 入れないもの |
|---|---|---|
| **顧客名/** | その顧客のプロジェクト フォルダー | 複数の顧客が混ざった資料 |
| **日付_プロジェクト/** | 1 つのプロジェクトのすべて。日付は開始日 | — |
| **01_契約** | 契約書、見積書、発注書、NDA、請求書 | 作業中の下書き |
| **02_資料** | 顧客から受け取った元の資料 (手を加えない) | 自分が直したファイル |
| **03_作業** | 下書き、作業ファイル、打ち合わせのメモ | 送った最終版 |
| **04_成果物** | 顧客に送った最終版だけ | 下書き・途中の版 |
| **99_保管** | 終わった後に残すもの、もう使わないもの | — |

## ツリーの例

```
ACME/
└─ 2026-11-18_Webサイト改修/
   ├─ 01_契約/
   │  └─ 2026-12-01_ACME_契約書_署名済み.pdf
   ├─ 02_資料/
   ├─ 03_作業/
   ├─ 04_成果物/
   │  └─ 2026-12-20_ACME_デザイン案_v03.pdf
   └─ 99_保管/
```

## 名前の付け方

- パターン: `日付_顧客_文書種類_vバージョン.拡張子`
- 例: `2026-11-18_ACME_提案書_v03.pptx`、`2026-12-01_ACME_契約書_署名済み.pdf`
- ファイル名に `_final` や「最終」を付ける代わりに **日付** を使います。いちばん新しい日付が最新版です。
- バージョンは `_v01` から 2 桁で。

## 整理を続けるコツ

- 最終版は **04_成果物 にだけ** 置きます。ほかの場所に同じファイルをコピーしておきません。
- 02_資料 の元データは直さず、直すときは 03_作業 にコピーして直します。
- プロジェクトが終わったら顧客フォルダーの中にそのまま置くか、整理するものだけ 99_保管 に移します。
- 顧客名は 1 つの書き方にそろえます (ACME と エーシーエムイー を混ぜない)。

## こんなときは別のスタイルを

- 顧客の区別なく個人のことと仕事が混ざっている → **PARA**
- ソフトウェアを作るプロジェクト → **IT システム開発文書**
