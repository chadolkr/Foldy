# ACE の使い方

> ニック・マイロ (Linking Your Thinking) が考えた三つの区分の整理法です。何をしたいかで分けます: 理解したいなら Atlas、日付で追いたいなら Calendar、行動したいなら Efforts。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの | 入れないもの |
|---|---|---|
| **Atlas** | 知ったこと・集めた知識 | 日付が大事な記録 |
| **Atlas/Cards** | 考えや概念を自分の言葉でまとめたメモ | 他人が書いた原文 |
| **Atlas/Sources** | 本・記事・動画などの出典資料とその要約 | 自分の行動 |
| **Calendar** | 日付のある記録。議事録、日誌、その日のメモ | 日付に関係ない知識 |
| **Efforts** | 取り組んでいること・プロジェクト。一つごとにフォルダー一つ | 終わってもう見ないもの |

## ツリーの例

```
Atlas/
├─ Cards/
│  └─ よい習慣をつくる.md
└─ Sources/
   └─ 複利で伸びる1つの習慣 要約.md
Calendar/
└─ 2026-11-24_週次ミーティング.md
Efforts/
└─ ブログを始める/
```

## 名前の付け方

| 対象 | ルール | 例 |
|---|---|---|
| Calendar の記録 | 日付_内容 | `2026-11-24_週次ミーティング.md` |
| Efforts のフォルダー | 取り組むことの名前 | `ブログを始める` |

## 整理を続けるコツ

- 区分の名前は英語のままにします。ほかの人の説明や例と同じなので、まねしやすくなります。
- 最初は Atlas の中に Cards と Sources だけを置き、必要になったら増やします。
- Efforts で終わったことは、フォルダーごと Atlas か保管フォルダーへ移します。

## こんなときは別のスタイルを

- メモより仕事の文書が多いなら → **PARA**
- やることの流れを管理したいなら → **GTD (Getting Things Done)**
