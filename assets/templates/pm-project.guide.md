# 프로젝트 관리 (PMBOK 5단계) 사용법

> 업종과 상관없이 쓰는 프로젝트 문서 정리법이에요. 미국 프로젝트관리협회(PMI)의 PMBOK 가이드가 말하는 다섯 프로세스 그룹(착수·계획·실행·감시와 통제·종료) 순서로 폴더를 나눕니다.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 |
|---|---|
| **01_착수** | 프로젝트 헌장, 이해관계자 목록, 착수 승인 |
| **02_계획** | 범위·일정(WBS)·예산·품질·위험·의사소통 계획 |
| **03_실행** | 만든 결과물, 회의록, 작업 자료 |
| **04_감시와통제** | 주간·월간 진척 보고, 변경 요청, 이슈·위험 기록 |
| **05_종료** | 최종 보고, 인수 확인서, 교훈(회고), 계약 종료 |
| **99_보관** | 지난 버전, 더는 안 쓰는 것 |

## 유지 요령

- 감시와 통제는 실행과 함께 계속 돌아가요. 보고·변경 요청은 그때그때 04에.
- 끝날 때 교훈을 05_종료에 남기면 다음 프로젝트가 쉬워져요.

## 이럴 땐 다른 스타일을

- 소프트웨어를 만드는 프로젝트라면 → **IT 시스템 개발 문서**
- 도면·모델을 여러 팀이 주고받는 건설·설계라면 → **건설·설계 정보 관리**
- 고객사별로 계약·산출물만 나누면 충분하다면 → **고객·프로젝트 업무**
