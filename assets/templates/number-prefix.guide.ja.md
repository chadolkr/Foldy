# 番号・日付を付けるの使い方

> いちばん簡単な整理法です。フォルダーの前に番号を付けると順番がいつも同じになり、ファイル名を日付で始めると名前順がそのまま日付順になります。

| フォルダー | 入れるもの |
|---|---|
| **00_受信** | ひとまずここへ。受け取ったファイル、どこに置くかまだ決めていないもの (一番上なのでいつも目に入ります) |
| **01_進行中** | いま取り組んでいること |
| **02_資料** | よく見る参考資料 |
| **03_完了** | 終わったがときどき見るもの |
| **99_保管** | 古くてほとんど見ないもの (99 なのでいつも一番下) |

## 受信フォルダーの使い方

1. 新しいファイルは悩まずに **00_受信** に入れます。
2. 週に 1 回、00_受信 を空にしながら 01〜03 に分けます。
3. 空になったら終わり! ためないことがポイントです。

## ファイル名

`2026-11-19_報告書.docx` のように **日付_内容** で名付けると、名前順で並べるだけで日付順になります。

## こんなときは別のスタイルを

- 進行中の仕事と、続けて受け持つことを分けたい → **PARA**
- フォルダーがとても多く、番号ですぐたどりたい → **Johnny.Decimal**
- 写真・スキャンのように日付がすべての資料 → **日付別の保管庫**
