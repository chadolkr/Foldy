# PARA 사용법

> 모든 자료를 "언제 끝나는가"를 기준으로 네 칸 중 하나에 넣습니다. 칸이 넷뿐이라 어디에 둘지 고민하는 시간이 짧습니다.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 | 넣지 않는 것 |
|---|---|---|
| **1_Projects** | 마감이나 완료 시점이 있는 일. 예: 이사 준비, 3분기 보고서, 여권 갱신 | 끝이 없는 일(그건 Areas) |
| **2_Areas** | 끝나지 않고 계속 책임지는 영역. 예: 건강, 재무, 자동차, 팀 운영 | 한 번 하고 끝나는 일 |
| **3_Resources** | 관심 주제별 참고 자료. 예: 요리법, 디자인 참고, 매뉴얼 | 내가 책임지는 일의 문서 |
| **4_Archives** | 끝났거나 더는 쓰지 않는 것. 위 세 칸에서 옮겨 온 폴더 | 지금 쓰는 자료 |

어디에 둘지 헷갈리면 이 순서로 물어보세요.

1. **언제 끝나나?** 날짜가 있으면 → 1_Projects
2. **계속 맡나?** 끝없이 관리해야 하면 → 2_Areas
3. **그냥 참고인가?** → 3_Resources
4. 셋 다 아니고 이제 안 쓰면 → 4_Archives

## 예시 트리

```
문서/
├─ 1_Projects/
│  ├─ 2026-11_이사/
│  └─ 2026-12_연말정산/
├─ 2_Areas/
│  ├─ 건강/
│  └─ 재무/
├─ 3_Resources/
│  └─ 요리/
└─ 4_Archives/
   └─ 2026-03_여권갱신/
```

## 이름 규칙

- 패턴: `날짜_주제_내용[_v버전].확장자`
- 예: `2026-11-18_이사_견적비교_v02.xlsx`, `2026-03-02_건강검진_결과.pdf`
- 프로젝트 폴더 이름은 `시작연월_이름`(2026-11_이사)으로 두면 시작순으로 정렬됩니다.
- 버전은 `_v01`, `_v02`처럼 두 자리. "최종", "진짜최종"은 쓰지 않습니다.

## 유지 요령

- 프로젝트가 끝나면 그 폴더를 **통째로** 4_Archives로 옮깁니다. 지우지 않습니다.
- 한 달에 한 번 1_Projects를 훑어 끝난 일을 보관으로 넘깁니다.
- 2_Areas는 자주 바뀌지 않습니다. 영역이 10개를 넘으면 너무 잘게 나눈 것은 아닌지 살펴보세요.
- 하위 폴더는 2~3단계 안에서 멈추는 것이 찾기 쉽습니다.

## 이럴 땐 다른 스타일을

- 자료가 아주 많고 번호로 바로 찾고 싶다면 → **Johnny.Decimal**
- 고객별로 일이 나뉘는 외주·영업이라면 → **고객·프로젝트 업무**
- 사진·영상이 대부분이라면 → **사진·영상 보관**
