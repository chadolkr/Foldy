# 业务分类体系 (ISO 15489) 使用方法

> 档案管理国际标准 ISO 15489 推荐的"业务分类体系"。不按人或部门，而按组织**所做的工作**来分：大的工作（职能）→ 其中的工作（活动）→ 一件具体事项，共三级。部门调整时文件夹不用改，适合公司、机构的共享盘。

## 每个文件夹放什么

| 层级 | 含义 | 示例 |
|---|---|---|
| **职能**（01~09 文件夹） | 组织承担的大块工作 | 02_财务、03_人事 |
| **活动**（职能里的文件夹） | 构成该职能的工作 | 02_财务/预算与决算 |
| **事项**（活动里的文件夹） | 一次具体的工作，最小单位 | 02_财务/预算与决算/2026_年度预算 |

| 职能文件夹 | 放什么 |
|---|---|
| **01_战略与规划** | 经营计划、目标、董事会和委员会会议 |
| **02_财务** | 预算、会计、税务、审计 |
| **03_人事** | 招聘、考勤、薪资、培训 |
| **04_采购与合同** | 报价、合同、订单、供应商 |
| **05_设施与设备** | 办公室、设备、车辆、物品 |
| **06_信息与IT** | 系统、账号、安全、档案管理 |
| **07_法务** | 法律审查、诉讼、规章、许可 |
| **08_对外关系** | 宣传、客户、媒体、活动 |
| **09_核心业务** | 本组织特有的主营业务（销售、生产、研究等） |

01~08 几乎每个组织都有（由澳大利亚国家档案馆的通用职能清单简化而来）。删掉本组织不做的部分。

## 示例树

```
我们公司/
├─ 02_财务/
│  ├─ 预算与决算/
│  │  └─ 2026_年度预算/
│  └─ 税务/
├─ 04_采购与合同/
│  └─ 2026_办公室搬迁/
└─ 09_核心业务/
   └─ 销售/
```

## 命名规则

| 对象 | 规则 | 示例 |
|---|---|---|
| 事项文件夹 | 年份_事项名 | `2026_办公室搬迁` |
| 文件 | 日期_内容 | `2026-11-24_租赁合同.pdf` |

## 保持整洁的诀窍

- 文件夹名称不用人名或部门名。用"04_采购与合同"，不用"小王的文件夹"。
- 深度不超过 职能 → 活动 → 事项 三级。想分得更细就把名称写具体。
- 需要长期保存的档案（合同、会计账簿）先定好保存期限，到期后清理。

## 这些情况适合其他风格

- 只有自己用的文档 → **PARA**
- 按项目划分的工作 → **项目管理（PMBOK 5 阶段）**
