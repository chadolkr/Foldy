# 设计与创作素材 使用方法

> 四个格子，把不能动的（原件）、正在做的（工作）、成果（导出）和灵感（参考）分开，不混在一起。

## 每个文件夹放什么

| 文件夹 | 放什么 | 不放什么 |
|---|---|---|
| **原件** | 收到的图片、照片、素材、字体 | 修改过的文件 |
| **工作** | 工作文件（psd、ai、fig、项目文件）及其版本 | 成品 |
| **导出** | 为交付或发布导出的成果（png、jpg、pdf、mp4） | 正在处理的文件 |
| **参考** | 参考资料、情绪板、规范 | 自己做的成果 |

## 示例树

```
品牌标志/
├─ 原件/
├─ 工作/
│  ├─ 标志_主版_v2.ai
│  └─ 标志_主版_v3.ai
├─ 导出/
│  ├─ 标志_网页_512.png
│  └─ 标志_印刷.pdf
└─ 参考/
```

## 命名规则

| 对象 | 规则 | 例子 |
|---|---|---|
| 工作文件 | 作品名_内容_v版本 | `标志_主版_v3.ai` |
| 导出文件 | 作品名_用途_尺寸 | `标志_网页_512.png` |

## 保持整洁的诀窍

- 原件不修改。需要修改时复制到工作文件夹再改。
- 工作文件不要覆盖，提高 v 编号另存，回退会更容易。
- 文件较大的作品，备份时先保住原件和工作。

## 这些情况适合其他风格

- 只想按日期堆放照片和视频 → **照片与视频归档**
- 向客户交付的工作 → **客户与项目工作**
