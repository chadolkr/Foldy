# AI 작업 폴더 사용법

> 프롬프트를 고쳐 가며 결과를 비교하는 일을 정리하는 폴더예요.

| 폴더 | 넣는 것 |
|---|---|
| **prompts** | 프롬프트. 고칠 때마다 v1, v2처럼 새 파일로 |
| **data** | 넣는 자료. 원본은 고치지 않기 |
| **outputs** | AI가 만든 결과. 이름에 날짜와 프롬프트 버전 |
| **evals** | 결과를 비교·채점한 기록 |

## 이럴 땐 다른 스타일을

- 코드를 Claude와 함께 짜는 프로젝트라면 → **Claude Code 프로젝트**
- 반복 작업을 스킬로 만들려면 → **Claude 스킬 하나**
