# 생활·가정 서류 사용법

> 한 해에 몇 번 찾는 서류를 "여섯 칸"으로 나눕니다. 급할 때 3번 클릭 안에 찾는 것이 목표입니다.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 | 넣지 않는 것 |
|---|---|---|
| **재무** | 세금 신고, 통장·카드 내역, 연말정산 | 일상 영수증 전부 |
| **건강** | 진료·처방 기록, 검진 결과 | — |
| **집** | 계약서·등기, 공과금·관리비, 가전 설명서 | — |
| **차량** | 등록증, 정비 내역, 보험 가입 증명 | — |
| **여권·신분** | 여권·신분증·증명서 사본 | 원본 실물 |
| **보험** | 보험증권, 약관, 청구 기록 | — |

## 예시 트리

```
생활서류/
├─ 재무/
│  ├─ 세금/
│  └─ 통장·카드/
├─ 건강/
│  ├─ 진료·처방/
│  └─ 검진/
├─ 집/
│  ├─ 계약·등기/
│  ├─ 공과금·관리비/
│  └─ 수리·설명서/
├─ 차량/
├─ 여권·신분/
└─ 보험/
```

## 이름 규칙

날짜_기관_내용 순서입니다. 날짜는 서류에 적힌 날짜를 씁니다.

| 대상 | 규칙 | 예 |
|---|---|---|
| 서류 | 날짜_기관_내용 | `2026-05-31_국세청_종합소득세신고.pdf` |

## 유지 요령

- 여권·신분, 보험처럼 민감한 서류는 폴더를 암호화하거나 비밀번호가 있는 백업에 둡니다. 클라우드에 올릴 때는 특히 주의하세요.
- 만료일이 있는 서류(여권, 보험)는 파일 이름이나 달력에 만료일을 함께 적어 둡니다.
- 5년이 지나 필요 없어진 서류는 직접 확인한 뒤에 정리합니다. Foldy는 아무것도 삭제하지 않습니다.

## 이럴 땐 다른 스타일을

- 서류가 아니라 일·공부 자료가 많다면 → **PARA**
- 날짜순으로 쌓기만 하고 싶다면 → **날짜별 보관함**
