# 사진·영상 보관 사용법

> 연도 → 날짜_행사명 순서로 두면 이름순 정렬이 곧 시간순이 됩니다. 원본은 한 곳에만 두고 절대 고치지 않습니다.

## 폴더별로 무엇을 넣나

| 폴더 | 넣는 것 | 넣지 않는 것 |
|---|---|---|
| **연도/** | 그해의 행사 폴더들 | 연도가 섞인 사진 |
| **날짜_행사명/** | 행사 하나. 날짜는 첫날 | — |
| **RAW** | 카메라·휴대폰에서 가져온 원본 그대로 | 보정한 파일 |
| **편집본** | 보정·자르기·합성한 파일 | 원본 |
| **내보내기** | 공유·인쇄용으로 줄이거나 바꾼 파일 | 작업 중인 파일 |

## 예시 트리

```
사진/
└─ 2026/
   ├─ 2026-08-02_여름휴가/
   └─ 2026-11-18_제주여행/
      ├─ RAW/
      │  └─ 2026-11-18_143205_제주여행_001.jpg
      ├─ 편집본/
      │  └─ 2026-11-18_제주여행_편집본_001.jpg
      └─ 내보내기/
```

## 이름 규칙

- 패턴: `날짜_시간_행사_일련번호.확장자` (촬영 시각 기준)
- 예: `2026-11-18_143205_제주여행_001.jpg`, `2026-11-18_제주여행_편집본_001.jpg`
- 카메라가 붙인 이름(IMG_1234)은 Foldy의 일괄 이름 변경에서 "촬영 시각으로 이름 만들기"로 한 번에 바꿀 수 있습니다.

## 유지 요령

- **RAW는 절대 고치지 않습니다.** 보정은 항상 복사본으로 편집본에서 합니다.
- 백업은 RAW만 있어도 나머지를 다시 만들 수 있습니다. 백업 순서는 RAW가 먼저입니다.
- 행사 이름은 짧게. 전체 경로가 길어지면 다른 기기로 옮길 때 문제가 생깁니다.
- 가져오기를 마친 날, 흔들리거나 겹친 사진은 바로 골라 두면 나중이 편합니다 (지우는 것은 직접 확인 후).

## 이럴 땐 다른 스타일을

- 사진이 문서의 일부(현장 사진, 증빙)라면 → **고객·프로젝트 업무**의 02_자료
- 사진보다 문서가 많다면 → **PARA**
