# 生活・家庭の書類の使い方

> 1 年に何度か探す書類を「6 つの区分」に分けます。急いでいるときに 3 回のクリックで見つけるのが目標です。

## フォルダーごとに何を入れるか

| フォルダー | 入れるもの | 入れないもの |
|---|---|---|
| **家計** | 税金の申告、通帳・カードの明細、年末調整 | 日常の領収書すべて |
| **健康** | 診療・処方の記録、健診の結果 | — |
| **家** | 契約書・登記、公共料金・管理費、家電の説明書 | — |
| **車** | 車検証、整備の記録、保険加入の証明 | — |
| **パスポート・身分証** | パスポート・身分証・証明書のコピー | 原本そのもの |
| **保険** | 保険証券、約款、請求の記録 | — |

## ツリーの例

```
生活書類/
├─ 家計/
│  ├─ 税金/
│  └─ 通帳・カード/
├─ 健康/
│  ├─ 診療・処方/
│  └─ 健診/
├─ 家/
│  ├─ 契約・登記/
│  ├─ 公共料金・管理費/
│  └─ 修理・説明書/
├─ 車/
├─ パスポート・身分証/
└─ 保険/
```

## 名前の付け方

日付_機関_内容 の順です。日付は書類に書かれた日付を使います。

| 対象 | ルール | 例 |
|---|---|---|
| 書類 | 日付_機関_内容 | `2026-05-31_税務署_確定申告.pdf` |

## 整理を続けるコツ

- パスポート・身分証、保険のような大事な書類は、フォルダーを暗号化するか、パスワード付きのバックアップに置きます。クラウドに上げるときは特に注意してください。
- 期限のある書類 (パスポート、保険) は、ファイル名かカレンダーに期限も書いておきます。
- 5 年たって不要になった書類は、自分で確かめてから整理します。Foldy は何も削除しません。

## こんなときは別のスタイルを

- 書類より仕事・勉強の資料が多い → **PARA**
- 日付順にためるだけにしたい → **日付別の保管庫**
